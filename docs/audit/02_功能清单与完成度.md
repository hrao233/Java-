# 02 功能清单与完成度

“完成”指当前入口具备能落到界面或文件系统的工作路径。“受限”指只能完成部分场景。“转交系统”指应用启动原生功能，结果由系统或外部程序处理。“仅展示”指存在标签或入口，但其字面含义未接上服务。表中的 Windows 差异是基于两者产品范围和本项目证据，实测覆盖见 [11](11_测试与运行验证记录.md)。

## 浏览与组织

| 功能 | 用户可见行为与实现证据 | 完成度、平台与限制 | 验证及与 Explorer 的差异 |
| --- | --- | --- | --- |
| 目录浏览、双击打开 | 侧栏、表格和图标视图打开目录。普通文件交系统默认程序。虚拟系统项走 Shell Verb。目录读取返回可显示条目及读失败计数。见 [open](../../src/main/java/edu/files/FileManagerApp.java#L1521-L1542)、[readDirectory](../../src/main/java/edu/files/LocalFiles.java#L87-L106)。 | 完成核心目录路径。Java NIO 和 JavaFX，文件打开需 JDK Desktop，Shell 项需 Windows。显示的是一个快照。 | U02、S15。默认应用和各类关联未全测。没有 Explorer 广泛的 Shell 虚拟目录、右键扩展和拖放。 |
| 地址栏和导航历史 | 按层级生成面包屑，带隐藏祖先和异步子文件夹菜单。可编辑绝对或相对路径、盘符、页面名，可打开文件。后退、前进和上级都是按钮，历史在导航成功后变更。见 [AddressBar](../../src/main/java/edu/files/AddressBar.java#L134-L267)、[地址解析与历史](../../src/main/java/edu/files/FileManagerApp.java#L398-L514)。 | 核心完成。相对路径在虚拟页以 Java 用户主目录为基准。输入提示来自最近记录。面包屑菜单才实际列子目录。活动任务期间导航禁用。 | U02 验证可编辑地址、双击、上级、前进、后退。Explorer 还有更丰富的 Shell 地址和路径补全。 |
| 侧栏和快速访问 | 主文件夹、图库、OneDrive、此电脑、网络、Linux。目录分支展开才读。六个默认固定文件夹，加用户固定和最多四个最近修改文件夹。见 [rebuildSidebar/directoryItem](../../src/main/java/edu/files/FileManagerApp.java#L1010-L1059)、[pins/latestFolders](../../src/main/java/edu/files/FileManagerApp.java#L1082-L1109)。 | 完成应用内快链。Windows 默认目录、近期索引等来源取决于本机，普通目录浏览跨平台路径可达。固定的路径可能后来失效。 | U01 启动，S16 验证修改时间归并。真实个性化和逐级展开未遍历。应用 Preferences 固定不等于 Explorer 固定。 |
| 详细表、大小图标、列表、平铺、内容 | 八种模式。详细表用 `TableView`，其他用行单元虚拟化。磁盘平铺可显示容量与进度条。首页无搜索时固定为自定义列表。见 [Mode、render](../../src/main/java/edu/files/BrowserView.java#L134-L152)、[render](../../src/main/java/edu/files/BrowserView.java#L251-L302)、[iconEntry](../../src/main/java/edu/files/BrowserView.java#L926-L973)。 | 完成常用视图。排序设置按 Page 存在内存，普通目录共享一份。列表使用行排图标，内容视图补时间和位置。 | U02 验证表格，U09 验证图库。八种未逐一交互。Explorer 的每文件夹布局、详细列自定义和原生列未对齐。 |
| 图库与缩略图 | 从图片文件夹或手动添加的来源递归取 PNG、JPG/JPEG、GIF、BMP，路径去重、合计最多 2,000。尺寸参与排版，多种大小、分组和滚动日期。见 [galleryWork](../../src/main/java/edu/files/FileManagerApp.java#L572-L599)、[galleryItems](../../src/main/java/edu/files/FileManagerApp.java#L1278-L1297)、[BrowserView 图库](../../src/main/java/edu/files/BrowserView.java#L762-L908)。 | 完成选定格式的本地图库。按扩展名候选，解码失败回退图标，缺失的来源可跳过。删除来源菜单要求至少留一处。 | U09、S15、P05。图片日期来自文件修改时间，非 EXIF 拍摄时间。没有云照片库、编解码器扩展或完整索引。 |
| 排序、分组 | 名称、类型、大小、修改时间等，按页面可增磁盘字段、位置和访问时间。分组字段用月份、大小区间或文本等标签。通常未分组的普通视图文件夹在前。见 [sortItems/availableFields](../../src/main/java/edu/files/FileManagerApp.java#L693-L740)、[Field](../../src/main/java/edu/files/BrowserView.java#L81-L132)、[render/buildLines](../../src/main/java/edu/files/BrowserView.java#L251-L302)。 | 核心完成。排序用不区分大小写的字典序，`file10` 可排在 `file2` 前。分组方向复用排序方向，无独立状态。 | 静态，U02 已经过默认排序。Explorer 的自然数字排序、属性列和排序规则更丰富。 |
| 列筛选 | 详细表名称、修改日期、类型、大小支持复选分桶。列内任选，跨列同时满足。名称桶含拼音区间，日期按本地时区。导航/查询改变会清筛选。见 [openFilter](../../src/main/java/edu/files/BrowserView.java#L571-L623)、[ColumnFilters](../../src/main/java/edu/files/ColumnFilters.java#L29-L125)、[request](../../src/main/java/edu/files/FileManagerApp.java#L525-L539)。 | 有效。其他视图可沿用已选条件，但没有相同列头，需从「更多」清除。日期相对桶随日期变化，拼音分桶与搜索和排序独立。 | S19 验证 ICU 及跨列交集，未遍历筛选弹窗。Explorer 的过滤字段和分桶不完全相同。 |
| 搜索、取消与退出 | 输入后回车或点击按钮。普通目录递归按名称子串匹配，过滤不可见子树，收集最多 2,000 项，在发现额外结果时显示上限。首页及系统列表按其数据输入过滤，图库按图片来源查。见 [request/listingWork](../../src/main/java/edu/files/FileManagerApp.java#L516-L569)、[LocalFiles.scan](../../src/main/java/edu/files/LocalFiles.java#L170-L280)。 | 受限。大小写按 `Locale.ROOT`，不做内容搜索、Windows Search 查询语法和 Unicode 规范化。取消按遍历检查点，阻塞 I/O 仍可能等待。 | U03、S06、S15、P03–P04。未实点取消按钮。Explorer 在部分位置用其索引，并有属性及全文条件。 |
| 刷新与外部变化 | 刷新按钮重新读取当前页或系统位置，内部写入后也请求刷新。焦点回归触发最近修改文件夹刷新。见 [navigation](../../src/main/java/edu/files/FileManagerApp.java#L255-L282)、[afterWrite](../../src/main/java/edu/files/FileManagerApp.java#L1747-L1763)、[焦点事件](../../src/main/java/edu/files/FileManagerApp.java#L230-L232)。 | 手动刷新完成。目录、图库和读过的树分支缺少文件变更监听。「此电脑」刷新同时重取系统数据。 | U08 观察外部写入在手动刷新后才出现。Explorer 正常支持目录变更通知。 |

## 写入与查看

| 功能 | 用户可见行为与实现证据 | 完成度、平台与限制 | 验证及与 Explorer 的差异 |
| --- | --- | --- | --- |
| 复制、剪切、粘贴、移动 | 工具栏、右键或快捷键记选中路径，状态栏显示待粘贴。当前目录可粘贴，右键文件夹可粘贴到内部。复制暂存再发布，剪切移走源。见 [commandBar](../../src/main/java/edu/files/FileManagerApp.java#L285-L312)、[pasteInto/PasteItem](../../src/main/java/edu/files/FileManagerApp.java#L1620-L1689)。 | 局部完成。剪贴板只在应用内，不支持 Explorer 互通、拖放、替换/跳过选择或真正的写入取消。剪切异常时保留未处理尾部，跨盘非空目录移动失败。 | U06–U07、S01–S07、S17。数据安全见 [06](06_文件操作与数据安全.md)。 |
| 新建文件夹、文件和快捷方式 | 普通目录非搜索时从注册类型新建。创建文件夹或空文件时避开同名。模板/注册数据暂存，快捷方式生成 `.url` 或通过 COM 写 `.lnk`，成功后原位命名。注册命令分支只启动外部向导。见 [NewItems.create](../../src/main/java/edu/files/NewItems.java#L99-L123)、[create/createItem](../../src/main/java/edu/files/FileManagerApp.java#L1544-L1579)。 | 主路径完成。Windows 注册项依赖本机、跳过 Handler/OptIn 等。读取失败时可能只有文件夹和快捷方式。非 Windows 有文本文档回退。命令向导的实际落盘、重命名、撤销由外部负责。 | S11 验证文件夹、文本、新建后改名与 `.url`，U01 发现 12 个可用类型。实际 COM `.lnk`、所有模板和外部注册命令未运行。 |
| 重命名 | 选中一个真实条目，在列表原位改名。回车或失焦提交，Esc 放弃文字输入。隐藏扩展名时保留原后缀，新建时也保留后缀。见 [BrowserView.editName](../../src/main/java/edu/files/BrowserView.java#L308-L382)、[renameSelected](../../src/main/java/edu/files/FileManagerApp.java#L1603-L1618)。 | 单项完成，依赖 NIO/平台。没有批量改名或改扩展名后的类型提醒。大小写特例和身份问题见 [06](06_文件操作与数据安全.md)。 | U05、S02、S06。Explorer 的批量同干名、冲突处理更完整。 |
| 删除和撤销 | 确认后移回收站。撤销仅记最近一次有写入且可逆的操作，支持新建、复制、移动和改名，按批次反向执行。删除没有应用内恢复。见 [trashSelected/applyChanges/undo](../../src/main/java/edu/files/FileManagerApp.java#L1692-L1732)。 | 有限，涉及回收需平台支持。无撤销栈、重做或可追踪的回收 ID，撤销可作用于后续变化的对象。 | U06–U07、S08–S11、S18、S20–S21。Explorer 回收站可恢复信息和系统撤销整合更广。 |
| 预览与详情 | 详情窗格显示当前快照的名称、路径、类型、大小、时间或磁盘字段。预览窗格显示常见图片及前 8 KiB UTF-8 文本，二进制一般因 NUL/替换字符拒绝。多选只显示计数。见 [refreshInspector/preview/propertiesText](../../src/main/java/edu/files/FileManagerApp.java#L1381-L1475)。 | 限定类型已实现。Office、PDF、音视频等没有解析器。UTF-8 截断于多字节字符中间可能误判，其他编码不适用，合法 U+FFFD 也被拒绝。图片错误可显示提示。 | U04 验证合成文本和 PNG。Explorer 可利用系统预览处理器和更多元数据。 |
| 属性 | Windows 真实路径由 `SHObjectProperties` 打开系统属性。虚拟页显示计数，非 Windows 显示本应用字段，多选只计数。见 [showProperties](../../src/main/java/edu/files/FileManagerApp.java#L1477-L1519)、[WindowsPlaces.showProperties](../../src/main/java/edu/files/WindowsPlaces.java#L167-L250)。 | 转交系统或有限展示。启动原生页的实际属性数量取决于系统，应用不计算目录总大小。 | 原生对话框未打开验证。详情窗格与原生属性是两个入口。 |

## 位置、偏好与交互

| 功能 | 用户可见行为与实现证据 | 完成度、平台与限制 | 验证及与 Explorer 的差异 |
| --- | --- | --- | --- |
| 收藏、最近使用、最近修改 | 收藏是应用保存的真实路径集合。最近使用合并本应用打开成功记录与 Windows Recent 快照。最近修改根据当前时间戳、应用写记录、已知目录单层与 Windows Search 前 256 条计算。见 [homeWork](../../src/main/java/edu/files/FileManagerApp.java#L601-L626)、[refreshModifiedFolders](../../src/main/java/edu/files/FileManagerApp.java#L1094-L1123)、[Recently modified](../../src/main/java/edu/files/LocalFiles.java#L108-L153)。 | 已有独立机制。历史路径可失效，内容机会性更新，最近修改不是全盘实时发现。首页「活动」列数据区为空。 | U01、S16。Explorer 的最近项目、账号活动和同步范围更广。 |
| 「已共享」 | 首页此标签显示 `networkItems`，来自手动网络路径和已映射网络盘。见 [homeWork](../../src/main/java/edu/files/FileManagerApp.java#L601-L609)、[namespace 数据](../../src/main/java/edu/files/FileManagerApp.java#L1299-L1302)、[活动列](../../src/main/java/edu/files/BrowserView.java#L656-L664) 和 [数据行](../../src/main/java/edu/files/BrowserView.java#L744-L760)。 | 仅展示本地网络入口，没有枚举用户共享、云盘共享或管理权限，活动列没有业务数据。 | 静态。和 Explorer/云提供商的共享主体、状态及操作不同。 |
| 此电脑与磁盘工具 | 获取盘根、本机 Shell 项和盘属性。工具菜单有清理、优化、格式化，按盘种类限制并调用 Windows 界面。见 [WindowsPlaces.load](../../src/main/java/edu/files/WindowsPlaces.java#L36-L102)、[driveForTools](../../src/main/java/edu/files/FileManagerApp.java#L835-L855)、[系统工具](../../src/main/java/edu/files/WindowsPlaces.java#L252-L295)。 | 盘栈展示已实现。Windows 工具是系统代理入口。非 Windows 有根和 FileStore fallback。 | 启动经过系统数据读取。真实格式化、清理和优化未执行，具体风险见 [06](06_文件操作与数据安全.md)。 |
| 网络、媒体、WSL、OneDrive | 可按 UNC 保存网络书签，浏览网络用 `explorer.exe`，映射/断开用 Windows 对话框或 API。媒体是浏览网络或打开 HTTP(S)。WSL 名称来自注册表，OneDrive 取现有环境路径。见 [网络入口](../../src/main/java/edu/files/FileManagerApp.java#L1304-L1379)、[Windows 网络适配](../../src/main/java/edu/files/WindowsPlaces.java#L327-L362)、[位置脚本](../../src/main/resources/edu/files/windows-places.ps1#L20-L40)。 | 转交或局部。UNC 语法校验不验证当前连通性，应用没有网络发现、设备流媒体协议、云同步或 WSL 管理实现。 | 代码已读。实机映射、断开、UNC/WSL/云文件行为未验。 |
| 设置与持久化 | 显示隐藏/受保护/扩展名、紧凑、复选框、侧栏及宽度。选项可重置固定目录。收藏、网络、图库和近期记录持久化。见 [restorePreferences](../../src/main/java/edu/files/FileManagerApp.java#L386-L396)、[viewItems/options](../../src/main/java/edu/files/FileManagerApp.java#L742-L795)、[保存路径与历史](../../src/main/java/edu/files/FileManagerApp.java#L1881-L1929)。 | 局部。排序、当前页、选区、撤销和窗口会话不持久化。系统设置是首次缺省来源。 | U01 验证注入设置加载，未测真实注册表重启。设置与 Explorer 并非双向同步。 |
| 选择、右键和快捷键 | 表格与图标可多选，支持复选框、全选、取消和反选。右键命令依条目类型、当前页和活动任务启用。列表焦点支持 Enter、F2、Delete、Ctrl+C/X/V/A/Z。全窗口有 Ctrl+L、Alt+D、Ctrl+Shift+N。见 [start 键盘入口](../../src/main/java/edu/files/FileManagerApp.java#L180-L225)、[contextMenu](../../src/main/java/edu/files/FileManagerApp.java#L858-L899)、[选择同步](../../src/main/java/edu/files/BrowserView.java#L1022-L1107)。 | 基本完成。列表快捷键有焦点限制，文字输入控件保留自己的编辑。无 Tabs、双栏、拖放和 Explorer Shell 扩展右键。 | U05–U07 包含应用控件与 Ctrl+Z，真实键鼠与辅助功能需单独验。 |
