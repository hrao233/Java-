# 01 项目概况与技术栈

这是一个单窗口桌面文件管理器。它把普通目录、系统位置、首页和图库显示在同一界面中。普通目录以文件系统路径为入口。Windows 原生集成负责补充系统位置、视觉资源和个别系统对话框。首页、图库、「此电脑」等是应用自定义页面，有各自的数据来源。见 [FileManagerApp.Page 和 Location](../../src/main/java/edu/files/FileManagerApp.java#L53-L77) 与 [listingWork](../../src/main/java/edu/files/FileManagerApp.java#L552-L564)。

这里的动机由实际调用和被解决的问题推导。仓库缺少原始选型记录。

## 从源码运行

在项目根目录使用 JDK 21 或支持 `--release 21` 的更新 JDK，需具备相应 JavaFX 平台原生库与可交互桌面。Windows 集成功能还依赖 Windows PowerShell、系统查询权限和安装组件。

```powershell
mvn -B test
mvn -B package
mvn javafx:run
```

`mvn test` 当前执行编译和资源复制，Surefire 报告无项目内测试。审查所用环境为 Windows 11 25H2（26200.9974）、Oracle JDK 27、Maven 3.10.0，目标字节码为 Java 21。Java 21 JVM 实机和 EXE 分发链列为未验。见 [11](11_测试与运行验证记录.md)。

非 Windows 有 JavaFX 与本地文件功能的回退代码，包括 NIO 根目录、用户主目录推导和点号隐藏规则。`WindowsPlaces.readScriptOutput` 在非 Windows 返回空表，`NewItems.catalog` 放入默认文本文档。系统入口的显示与平台判断并不完全一致，例如侧栏仍构建 Linux 页。这属于静态可达的回退路径，实际平台兼容性需运行验证。见 [根目录与回退](../../src/main/java/edu/files/WindowsPlaces.java#L36-L90)、[脚本平台检查](../../src/main/java/edu/files/WindowsPlaces.java#L131-L150)、[新建回退](../../src/main/java/edu/files/NewItems.java#L90-L96)、[侧栏构建](../../src/main/java/edu/files/FileManagerApp.java#L1010-L1039)。
