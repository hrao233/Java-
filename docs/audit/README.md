# Java 文件管理器工程审查

审查面向 `javafx-file-manager` 当前工作树，覆盖 Java、JavaFX 样式、Windows PowerShell 脚本、配置与现有生成物的来源。测试用独立临时夹具和从源码构建的类。代码证据的行号对应本地 `main` 的 `d22d680` 加原有五处修改和一个未跟踪脚本。版本和环境见 [01](01_项目概况与技术栈.md)。

## 核心结论

**最高优先级是复制目录的撤销。** 目标的深层文件已被改写，外层目录记录仍可能相同。隔离测试中撤销把包含新内容的整棵目标树移出了原位置，源仍只有旧内容。优先收紧自动撤销范围，然后用可核对的文件身份和每项结果改进移动、重命名、回收。见 [文件安全 F01–F04](06_文件操作与数据安全.md) 和 [测试 S08、S09、S20](11_测试与运行验证记录.md)。

| 优先关注 | 已观察的事实和开发影响 |
| --- | --- |
| P0 复制目录撤销 | 比较外层 `Entry` 无法识别深层写入，S08 已复现。 |
| P1 由路径代替对象身份 | 同名替换后，移动撤销搬错文件，粘贴获取了在记录之后出现的替代品。S09、S12 已复现。 |
| P1 批量部分成功 | 普通 IO 错误能返回已写前缀。回收缺失项产生的运行时异常会使前缀结果丢失。S04–S05、S20 证实。 |
| P1 跨卷移动非空目录 | 本机双卷验证中，文件移动成功，非空目录移动失败且源保留。S17 已复现。 |
| P1 写入反馈和取消 | 文件写入只有忙状态，不能在应用内停止复制。全部由一条磁盘队列处理，慢任务对其它请求的排队影响需测。见 [06](06_文件操作与数据安全.md) 和 [07](07_并发与性能分析.md)。 |

五个有价值的设计可继续保留。`LocalFiles` 的可独立验证与值记录，读成功后提交导航，复制先暂存并保守处理冲突，磁盘与图标工作分开及回退图，虚拟化视图间复用选择。每项都有当前收益和未来代价。见 [08](08_代码质量与技术债务.md)。

核心浏览、文件操作、有限搜索与预览、图库、过滤、内部剪贴板及偏好均有实现。系统属性、磁盘工具和部分网络行为依赖 Windows。首页「已共享」显示网络位置，「活动」列没有数据，ShellNew 命令项只转交外部向导。精确功能边界和实测编号见 [02](02_功能清单与完成度.md)。

单窗口架构能承接后续修补。先整理写入结果和撤销安全，再按需要抽取浏览上下文和平台能力。下一阶段推荐验收深层编辑、同名替换、部分成功和跨卷失败四类夹具下的数据与界面一致性。多标签页、双栏和归档浏览在这些边界稳定后评估。见 [10](10_后续开发路线图.md)。
