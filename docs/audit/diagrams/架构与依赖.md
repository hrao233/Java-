# 架构与依赖图

箭头方向为数据请求、直接调用或构造回调。平台依赖图的箭头从使用方指向被使用方。叙述和代码引用见 [03](../03_现有软件架构.md)。

## 核心类关系

```mermaid
classDiagram
    class FileManagerApp {
      Location location
      Listing listing
      Task activeTask
      Transfer transfer
      List undo
      start(Stage)
      stop()
    }
    class BrowserView {
      Settings settings
      Set selected
      render()
      reveal()
      editName()
    }
    class AddressBar {
      List crumbs
      long popupRevision
      beginEdit()
      setLocation()
    }
    class BrowserItem {
      Path path
      Kind kind
      Entry entry
      Disk disk
    }
    class LocalFiles {
      readDirectory()
      search()
      copy()
      move()
      trash()
    }
    class NewItems {
      catalog()
      create()
      createShortcut()
    }
    class WindowsPlaces {
      load()
      readScriptOutput()
      showProperties()
    }
    class SystemIcons {
      Map cache
      graphic()
      close()
    }
    class ColumnFilters {
      Map selected
      options()
      includes()
    }
    class UiGlyph {
      graphic()
    }
    FileManagerApp *-- BrowserView : 持有并接收回调
    FileManagerApp *-- AddressBar : 持有并接收回调
    FileManagerApp *-- SystemIcons : 建立和关闭
    FileManagerApp ..> BrowserItem : 根据数据建立列表
    FileManagerApp ..> LocalFiles : 文件系统工作
    FileManagerApp ..> NewItems : 新建
    FileManagerApp ..> WindowsPlaces : 系统位置和工具
    FileManagerApp ..> UiGlyph : 命令图形
    BrowserView *-- ColumnFilters : 列筛选
    BrowserView ..> BrowserItem : 展示和选择
    BrowserView ..> SystemIcons : 图标
    BrowserView ..> LocalFiles : 图片扩展名判定
    BrowserView ..> UiGlyph : 交互图形
    ColumnFilters ..> BrowserView : 使用 Field
    ColumnFilters ..> BrowserItem : 计算属性桶
    AddressBar ..> UiGlyph : 地址栏图形
    BrowserItem ..> LocalFiles : 记录 Entry
    WindowsPlaces ..> BrowserItem : 磁盘及 Shell 项
    SystemIcons ..> WindowsPlaces : 读取图标脚本
    NewItems ..> WindowsPlaces : ShellNew 及 LNK
    NewItems ..> LocalFiles : 名称校验与改名
```
