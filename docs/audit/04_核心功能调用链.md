# 04 核心功能调用链

下面按用户动作追踪。FX 指 JavaFX Application Thread。磁盘线程串行执行文件系统任务，任务的成功、失败和取消回调回到 FX。系统图标另由图标线程获取，JavaFX 图片加载有自己的后台机制。图中省略仅参与布局的控件。见 [Mermaid 时序图](diagrams/核心交互时序.md)。

## 1. 启动

`main → Application.launch → start(Stage)`。FX 线程创建窗口、`SystemIcons`、`BrowserView`、导航树、菜单和状态栏，加载 CSS、窗口偏好与快捷键。`stage.show` 后 `loadPlaces(true)` 在磁盘线程顺序执行 `WindowsPlaces.load` 与 `NewItems.load`。完成后 FX 保存系统快照及类型目录，恢复偏好，重建侧栏，另起虚拟线程扫描最近修改，再调用 `refresh` 请求首页。读取异常进入 `runTask.onFailed`，状态为失败并弹提示。脚本读取为空时有默认目录和盘信息回退，类型目录仍能构建。窗口先出现，避免把本机 Shell 启动时间放在首帧之前。U01 通过。见 [start](../../src/main/java/edu/files/FileManagerApp.java#L171-L240)、[loadPlaces](../../src/main/java/edu/files/FileManagerApp.java#L367-L396)、[系统数据](../../src/main/java/edu/files/WindowsPlaces.java#L36-L90)。

## 2. 双击目录

详细表的行监听 primary 双击并确认命中数据格，图标项通过 `selectableEntry` 检查同一锚点且已选。两者调用 `onOpen → FileManagerApp.open → navigate → request`。磁盘线程执行 `readDirectory`，把 `LocalFiles.Entry` 转成 `BrowserItem`。成功后 FX 提交位置和 `listing`，记录旧位置，清前进栈、记访问时间、更新面包屑并渲染。读取失败保留当前页和历史，弹出异常。先读取再提交避免因无权限而留下显示路径与内容不一致的页面。U02 通过详细表。见 [表格双击](../../src/main/java/edu/files/BrowserView.java#L424-L440)、[图标双击](../../src/main/java/edu/files/BrowserView.java#L975-L994)、[navigate/request](../../src/main/java/edu/files/FileManagerApp.java#L493-L539)、[open](../../src/main/java/edu/files/FileManagerApp.java#L1521-L1531)。

## 3. 上一级目录

上箭头的事件调用 `parentLocation`。有父路径时转到父路径，盘根或 UNC 根回到所属虚拟页。`navigate` 与双击复用相同请求及失败处理，成功则把离开的目录压进后退栈。`history(from,to)` 则先 peek 目标，成功才对两个栈做 pop/push。一个是按位置关系导航，一个是按访问顺序导航。U02 同时验证这两种规则。见 [navigation](../../src/main/java/edu/files/FileManagerApp.java#L255-L282)、[containerPage](../../src/main/java/edu/files/FileManagerApp.java#L446-L450)、[parentLocation/history](../../src/main/java/edu/files/FileManagerApp.java#L486-L514)。

## 4. 搜索文件

按钮或文本框回车调用 `search`，用输入的 `strip()` 值请求当前 `Location`。普通目录交 `LocalFiles.search → scan`，用真实根递归遍历、筛 DOS 可见性、比较小写名称，访问时检查取消，达到额外命中的阈值后终止。无法读的子项计数，根目录打开失败经任务报错。其他页面按各自数据源查。FX 成功后提交 `activeQuery` 与列表，清位置/查询变化前的筛选，并更新搜索结果计数。点击取消触发 `Task.cancel`，旧结果继续显示。扫描放在后台可让控件继续绘制，整批返回实现简单但没有流式结果。U03、S15、P03–P04。见 [导航和取消入口](../../src/main/java/edu/files/FileManagerApp.java#L268-L277)、[listingWork](../../src/main/java/edu/files/FileManagerApp.java#L516-L599)、[scan](../../src/main/java/edu/files/LocalFiles.java#L208-L281)。

## 5. 复制并粘贴

工具栏、上下文菜单或 Ctrl+C 进入 `rememberSelection(false)`，FX 记录路径与模式。切换目录后粘贴调用 `pasteInto → PasteItem.change → applyChanges`，真实目标也可由右键文件夹给出。磁盘线程 `processChanges → PasteItem.paste → LocalFiles.copy`，先检查目标，再把数据复制至目标卷暂存目录，发布到正式名，保存实际 `Entry`。FX 根据已写前缀记录逆操作和父目录修改并重读列表，复制剪贴板仍可用。冲突或 I/O 失败停止后续条目，若已有写入则仍刷新。暂存解决可见半成品，不能把整个批次变成事务。U06、S01–S04。见 [命令栏](../../src/main/java/edu/files/FileManagerApp.java#L285-L312)、[传输与变更](../../src/main/java/edu/files/FileManagerApp.java#L1620-L1689)、[copy](../../src/main/java/edu/files/LocalFiles.java#L317-L363)、[Outcome](../../src/main/java/edu/files/FileManagerApp.java#L1710-L1763)。

## 6. 剪切并移动

Ctrl+X 或工具栏记录 `Transfer(move=true)`，此时源仍在原处。粘贴经同一调度，`PasteItem.paste` 调 `LocalFiles.move`，普通同卷走 NIO 移动。如果源父目录与目标相同，返回无变化。每个成功处理过的项从剪贴板移除，失败项及尾部保留，撤销只登记真正发生的写入。直接使用 NIO 可用同卷重命名能力，跨卷非空目录需要应用层协议。U07、S05、S17。见 [rememberSelection/pasteInto/PasteItem](../../src/main/java/edu/files/FileManagerApp.java#L1620-L1689)、[LocalFiles.move](../../src/main/java/edu/files/LocalFiles.java#L370-L394)。

## 7. 重命名

工具栏、右键和 F2 进入 `renameSelected`，仅支持一个实际条目。FX 的 `BrowserView.editName/reveal` 把该项滚到可见，以 `NameEdit` 建临时文本输入。Enter 或失焦提交，Esc 放弃，扩展名由当前显示规则决定是否固定。回调经 `childNamed` 校验后建立相向的两个 `LocalFiles.rename` 闭包。磁盘任务用 NIO 移动或大小写专用 `renameTo`，FX 写后刷新并 `Platform.runLater` 重新定位。无效名字立即报错，I/O 异常按写入结果报错。编辑属于视图而改名属于 I/O，有利于把 UI 取消与实际文件变更区分。U05、S02、S06。见 [行内编辑](../../src/main/java/edu/files/BrowserView.java#L308-L382)、[renameSelected](../../src/main/java/edu/files/FileManagerApp.java#L1603-L1618)、[文件名与改名](../../src/main/java/edu/files/LocalFiles.java#L287-L315)。

## 8. 删除文件

Delete、右键或工具栏进 `trashSelected`。App 取当时选择，用 FX 确认对话框的 OK 结果构造命令。磁盘线程检查 `Desktop.Action.MOVE_TO_TRASH` 支持后调用系统回收。成功刷新目录，普通回收无自己的逆操作。返回 false 变成 IOException，缺失路径可能是运行时异常。系统回收比直接按路径永久删除更贴近桌面习惯，实现与可用性由 OS/JDK 提供。S18、S20、S21 验证底层回收成功、批量遇到缺失项和占用失败。UI 确认属静态证据。见 [trashSelected](../../src/main/java/edu/files/FileManagerApp.java#L1692-L1722)、[LocalFiles.trash](../../src/main/java/edu/files/LocalFiles.java#L300-L305)、[desktopFor](../../src/main/java/edu/files/LocalFiles.java#L435-L440)。

## 9. 撤销上一次操作

Ctrl+Z 或「更多 → 撤消」进 `undo`。上次真实写入留下的可逆命令此前已反转。FX 把逆闭包包装为一批新的正向 `Change`，磁盘线程从首项执行。复制校验根快照后回收，移动和重命名搬回原路径，新建标记经校验后删空目录或文件。FX 去除已执行项，失败及之后的项保留并刷新或报错。闭包比为每种命令建一套可持久日志轻量，代价是记录缺少文件身份、操作详情和重启恢复能力。U06–U07、S08–S11。见 [PasteItem.undo](../../src/main/java/edu/files/FileManagerApp.java#L1679-L1689)、[undo/processChanges](../../src/main/java/edu/files/FileManagerApp.java#L1724-L1745)、[Created.undo](../../src/main/java/edu/files/NewItems.java#L40-L55)。安全边界见 [06](06_文件操作与数据安全.md)。

## 10. 选中文件并预览

表格选择监听或图标选择同步调用 `onSelection → selectionChanged → refreshInspector`。FX 取消前一个文本任务并清面板。图片走 JavaFX `Image` 的后台加载，失败处理只作用于仍挂在面板的 `ImageView`。普通文件在磁盘线程读前 8,192 字节，按 UTF-8 检查 NUL、替换字符，FX 成功回调核对仍是当前任务才设置 `TextArea` 或提示。窗口没开预览、有多选或选到虚拟项时只显示对应状态。限制预览字节可避免读全文件，但编码判定和共享磁盘队列都有代价。U04。见 [BrowserView.syncSelection](../../src/main/java/edu/files/BrowserView.java#L1061-L1076)、[refreshInspector/preview](../../src/main/java/edu/files/FileManagerApp.java#L1381-L1461)。

## 11. 系统图标与缩略图

可见单元格先请求 `SystemIcons.graphic`。FX 计算 DPI 像素、查缓存并先给回退图。未命中按键合并等待者。图标线程用 `FileSystemView`，特殊位置则读取 Windows 图标脚本返回的 Base64 PNG。完成回 FX 把 BufferedImage 转为 JavaFX 图像，再更新仍存活的视图。图库或大图标对图片另用 `BrowserView.thumbnail`，键含路径、尺寸和修改时间，JavaFX 后台解码，成功切换 ImageView。分离图标和缩略图能让未知格式保留系统图标，列表也无需等所有解码才出现。U09 验证本地文件图标请求完成和图库缩略图。见 [SystemIcons.graphic/request](../../src/main/java/edu/files/SystemIcons.java#L62-L132)、[finish](../../src/main/java/edu/files/SystemIcons.java#L163-L192)、[galleryEntry](../../src/main/java/edu/files/BrowserView.java#L823-L856)、[iconGraphic/thumbnail](../../src/main/java/edu/files/BrowserView.java#L997-L1020)。
