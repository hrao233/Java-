# 用户使用手册

## 安装、便携和设置

下载安装版时核对发行页的 SHA-256。直接运行安装程序，选择当前用户范围的安装目录和所需快捷方式。首次发布的候选安装程序为未签名文件。应从项目发行页获取与校验值相符的文件，并按设备策略处理系统提示。 [发行页](https://github.com/hrao233/Java-/releases)

便携版解压后保留 `JavaFXFileManager.exe`、`app`、`runtime` 和许可文件的目录结构，可移动整个文件夹。遇到启动错误时，从 PowerShell 运行同目录的 `JavaFXFileManager-Diagnostics.exe` 查看启动输出。若诊断显示 `could not find java.dll`，请把便携目录整体移至英文路径，或为安装版选一个英文路径。JDK 21 启动器可能无法从包含其系统代码页之外字符的路径启动。 [验证记录](development/13_独立打包与正式发布/02_验证与人工验收.md#github-actions-安装回归)

设置保存在当前用户 `HKEY_CURRENT_USER\Software\JavaSoft\Prefs` 下的 `/edu/files/explorer` 节点。窗口布局、收藏和显示设置可在重启及重新安装后沿用。剪切、撤销或未完成文件任务属于当前会话。在 Windows「已安装的应用」搜索 `JavaFXFileManager` 即可卸载。卸载负责清理安装目录中的程序文件和安装时创建的快捷方式。应用所管理的文件应放在安装目录之外。

## 浏览与文件操作

- Ctrl+L 输入目录并按回车。搜索支持目录递归名称匹配。可使用标签页、双栏、排序、筛选和文本或图片预览。普通 NTFS 目录支持自动刷新，搜索和其他目录可以用 F5 手动刷新。
- 文件可通过复制粘贴、右键或跨栏命令转移。应用与资源管理器之间用 Ctrl 拖放或复制粘贴。应用内可对已验证的同卷对象执行 Shift 拖放移动。
- 冲突时「跳过」保留原项目，「保留两者」选择新的副本名，「取消剩余操作」保留已提交项目。查看任务记录核对每项及目标。
- 撤销可用于最近一次受支持的移动或重命名。程序只有核实相同对象及原位置后才会提交。回收交 Windows 回收站，按需从系统回收站恢复。
- 「核查结果」列出回执未知的源和目标。先确认两边实际内容再决定是否重试。强制关机或结束进程可能留下尚未核实的暂存文件。
- 跨应用移动、同名覆盖、合并目录及跨卷目录移动超出当前承诺范围。文件夹跨卷转移时，可先复制，核对内容和权限，再从原位置单独处理。操作时避免并发重命名、删除、替换及为同一对象增删硬链接。 [详细安全边界](development/12_发布前质量审查/03_文件安全与发布边界.md)
