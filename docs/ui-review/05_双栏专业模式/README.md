# 4.1.5 双栏专业模式与布局独立化

基线为 `8b9bf6febb2711c742375a9b3ff05d3e3afeee0a`。

左右栏可分别选择传统、米勒列式或混合布局。共享工具栏显示「左栏布局」或「右栏布局」，菜单绑定打开时对应的浏览上下文。各栏保留自己的路径、历史、布局和视图设置。切换标签或重新打开右栏时，选区通过现有的文件身份核验恢复。检查器和共享命令随活跃栏切换。

双栏地址栏旁的放大镜可展开或收起该栏搜索框。滚动条滑块在浏览区域内降低默认不透明度，悬停时恢复原有对比度。

左右栏通过各自的 `MillerColumns` 和 `BrowserPane` 提交读取结果，共用现有读取执行器。祖先列只用于导航，文件拖放继续由当前目录的 `BrowserView` 接收，并复用来源和目标身份核验。

## 验证

Windows 11 上使用 Microsoft JDK 21.0.13 编译。8 项定向 JavaFX 集成测试通过，失败、错误和跳过均为 0。覆盖布局独立选择、标签与右栏恢复、搜索回退、异步请求归属、刷新、双向剪贴板传输、直接复制与移动、撤销、内部拖放、祖先列拒绝拖放，以及替换对象和导航后目标不能被重定向。拖放验证使用隔离夹具和 JavaFX 事件，未进行 Windows 资源管理器鼠标互拖复验。

搜索结果及特殊页面使用传统视图，返回普通目录后恢复所选布局。仅当前目录沿用自动刷新，祖先列可用 F5 更新。最窄窗口会截短较长的工具栏文字，布局菜单仍可打开，文件列表和层级列可横向滚动。
