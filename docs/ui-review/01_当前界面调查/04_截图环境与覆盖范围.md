## 夹具及采集方法

在独立目录生成 Project Aster、交付资料、空目录、五层长路径和包含 1,500 项的 CSV 目录。项目含合成的 Word、PDF、Excel、TXT、PNG、ZIP、Java、Python 和 CSV。三张路线图 PNG 由应用解码进入预览和缩略图。文件名涵盖中英文、空格和长名称，项目文件的修改时间分布在多个日期。复制与取消另使用 32 MiB 的隔离样本。 [夹具生成器](capture/fixture.py)

采集运行的是便携件副本。诊断启动器的配置加载采集入口，由它调用原 `FileManagerApp.start`，沿用包内应用类、CSS、JavaFX、JNA 和系统图标。采集入口使用内存偏好和内存剪贴板。首页、此电脑、最近记录及新建菜单使用合成的系统目录数据。真实磁盘目录、浏览请求、选区、图标、文件预览及任务界面由应用处理。此电脑的卷标、容量及路径用于演示，系统图标会按夹具所在的条目取得。 [控制与环境隔离](capture/VisualAudit.java) · [系统目录模型](../../../src/main/java/edu/files/WindowsPlaces.java#L31)

在被采集的应用窗口后放置纯色底窗，遮住圆角外缘可能出现的桌面内容。按 DWM 边界读取真实桌面组合像素，检测有无外部窗口遮挡。C02 的采集矩形包含主窗和右侧溢出弹层，以同一次取像保留全部菜单项。PNG 在写出后保持原始字节，复制后逐张核对 SHA-256，72 张图片经 Windows OCR 检查私人路径和账号模式，并抽看布局、菜单和任务画面。 [采集原理](capture/fixture.py)

## 覆盖边界

- A–F 的 64 个编号均有对应画面，共 72 张 PNG。B06 有超大图标、平铺、内容和图库四张，B10 有单选和多选两张，D13 有复制、移动和禁止三张。E03b 补充跳过结果，F03b 补充物理窗口尺寸。
- D11 使用真实按钮的悬停样式及 Tooltip。D12–D13 通过合成 JavaFX 拖放事件触发真实目标高亮及状态提示。采集范围为应用内反馈，外部应用原生拖放光标没有采集。
- E01、E02 与 E06 在隔离复制的暂存写入处等待。E03 使用实际同名冲突。E05 和 E08 通过任务工厂注入拒绝访问，E09 在实际夹具复制后模拟回执丢失。E07 拍摄确认后关闭，E10 使用真实不存在的目录。系统回收实际执行画面与真实受限目录画面超出本批截图范围。
- 当前项目为浅色主题，选项和查看菜单没有应用主题切换。深色主题不适用本次截图清单。

## 复采

在 Windows 桌面会话准备 JDK 21、PowerShell 7.2 及带 Pillow、openpyxl、ReportLab 的 Python。指定已核对哈希的便携 ZIP 和一个尚未创建的 NTFS 目录。采集期间会显示测试窗口，完成后在夹具的 `Images` 中生成 PNG 和尺寸记录。可传 `-Ids` 指定截图编号，F03b 另传 `-JavaFXScale '100%'`。 [入口脚本](capture/run.ps1)

```powershell
./capture/run.ps1 -PortableZip 'D:\Candidate\JavaFXFileManager-1.0.0-windows-x64-portable.zip' -Jdk21 'D:\BuildTools\jdk-21' -FixtureDirectory 'D:\FileManager-UI-Review\Recapture'
```
