# 界面结构与组件

## 与界面状态相关的异步路径

导航由 `BrowserPane` 提交 `BrowseIntent`。`BrowseRequest` 持有发起上下文、意图和任务，列表结果在有效归属下进入 `commitBrowse`。目录监听、选区身份以及预览回调沿用对应上下文的版本。后台标签恢复时重新读取列表。 [状态定义](../../../src/main/java/edu/files/BrowseContext.java#L45) · [浏览请求](../../../src/main/java/edu/files/FileManagerApp.java#L3166) · [提交](../../../src/main/java/edu/files/FileManagerApp.java#L3215)

复制、移动等操作由窗口级 `applyChanges` 创建 `FileOperationTask` 并在写入执行器运行。进度窗读取任务快照。实际回执在 `afterWrite` 生成状态说明并触发受影响页面刷新。未知写入结果显示独立入口。 [执行与回执](../../../src/main/java/edu/files/FileManagerApp.java#L2400) · [进度渲染](../../../src/main/java/edu/files/FileOperationProgress.java#L154) · [核查入口](../../../src/main/java/edu/files/FileManagerApp.java#L2517)

拖放命中由 `BrowserView.dragHit` 解析到文件项或空白区域。`FileManagerApp.fileDragOver` 使用当前目标和身份凭据计算操作是否可用，再更新行、标签或浏览面的 CSS 状态和底栏文字。 [命中解析](../../../src/main/java/edu/files/BrowserView.java#L243) · [悬停逻辑](../../../src/main/java/edu/files/FileManagerApp.java#L2003) · [高亮更新](../../../src/main/java/edu/files/FileManagerApp.java#L2151)
