# 当前视觉规范

`file-manager.css` 是应用自带的样式表。它按标签、导航条、分栏、侧边栏、工具栏、地址栏、菜单、首页、检查器、文件列表、任务和拖放状态组织选择器。主窗口、任务窗和同名冲突窗加载该表。部件的标题栏与窗口边缘由 Windows 绘制。 [样式表](../../../src/main/resources/edu/files/file-manager.css) · [主窗口挂载](../../../src/main/java/edu/files/FileManagerApp.java#L280) · [任务窗挂载](../../../src/main/java/edu/files/FileOperationProgress.java#L111) · [冲突窗挂载](../../../src/main/java/edu/files/FileConflictDialog.java#L72)

## 字体与字号

| 元素 | 当前实现 |
| --- | --- |
| 基础文字 | 根节点指定 Microsoft YaHei UI，13 CSS px。粗体用于选中侧边栏项、分组和任务标题。 |
| 导航按钮 | Segoe UI Symbol，21 CSS px，用于返回、前进、上一级、刷新等字符。 |

| 局部字号 | 新标签按钮 17，首页分区与图库分组 15，状态栏与任务辅助文字 12，任务主标题 25、阶段 15。 |

## 图标、缩略图和 DPI

常规文件图标来自 Windows 文件关联。`SystemIcons` 通过 Swing `FileSystemView.getSystemIcon` 获取系统图标，Windows Shell 脚本提供主文件夹、此电脑等命名空间图标。异步读取完成前显示内置占位图。列表细节行用 16 逻辑 px 图标，首页文件行用 28，独立检查器文件图标用 32。文件图标请求以 `ceil(逻辑大小 × outputScaleX)` 计算源像素，再按逻辑大小显示。 [图标实现](../../../src/main/java/edu/files/SystemIcons.java#L58) · [详情列表](../../../src/main/java/edu/files/BrowserView.java#L596) · [首页文件行](../../../src/main/java/edu/files/BrowserView.java#L864)

| 文件模式 | 图标标称尺寸（逻辑 px） |
| --- | ---: |
| 超大／大／中 | 136／92／60 |
| 小图标／列表 | 18／18 |
| 平铺／内容 | 40／44 |

常规图标视图中的图片缩略图保持长宽比。图库使用行高和比例适配视口，显示时按框裁切。当前窗口最小尺寸是 960×550 逻辑单位，初始场景为 1200×760。保存的窗口尺寸和位置会按当前屏幕工作区读取并约束。双栏有独立地址行和搜索行，地址栏空间不足时折叠较前的路径段。 [模式定义](../../../src/main/java/edu/files/BrowserView.java#L135) · [缩略图](../../../src/main/java/edu/files/BrowserView.java#L936) · [窗口限制](../../../src/main/java/edu/files/FileManagerApp.java#L304) · [恢复窗口](../../../src/main/java/edu/files/FileManagerApp.java#L379) · [面包屑折叠](../../../src/main/java/edu/files/AddressBar.java#L211)
