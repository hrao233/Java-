# 阶段 4.1.4 米勒列与混合浏览

以 `5e93f06d8d8395b525feb273ac8a44fe1b29c692` 为基线，沿用 4.1.2 的配色与控件样式。普通目录的工具栏提供传统、列式和混合三种布局。每个标签在浏览会话内保存自己的布局，默认使用传统。首页、此电脑、图库、搜索结果和双栏期间使用传统布局，返回单栏普通目录会恢复该标签的选择。

- **列式**按路径逐级显示目录，每列独立纵向滚动。进入深层目录时横向定位到当前列，长名称可悬停查看。单击目录进入下一层，双击文件打开，`Ctrl` 或 `Shift` 点击可选择多个项目。
- **混合**上方显示目录分支和当前目录的子目录，下方使用现有文件列表、图标视图、排序、筛选和选区。拖动横向分隔条可调整上下高度。
- 祖先列通过 `ReadExecutor` 逐列加载，只保留当前路径所需的列。导航、切换或关闭标签时取消旧读请求，回调按任务归属丢弃迟到结果。F5 刷新及现有当前目录监听触发的刷新会更新层级列。仅在祖先目录发生的变化，可按 F5 重新读取。祖先列的加载、空目录和读取失败分别显示提示。
- 文件命令继续针对现有浏览视图中的当前目录和选区，写入由原有身份验证保护。祖先列负责导航，焦点在该列时，文件剪贴板和新建快捷键不会触发。工具栏中的文件命令仍以地址栏显示的目录为目标。

## 验证

使用 Windows 11 和 Microsoft JDK 21.0.13 编译。8 项定向 JavaFX 集成测试全部通过，覆盖深层路径滚动、单击目录、同级分支切换、前进后退和地址提交、三种布局切换、搜索及双栏回退、目录监听、人工刷新恢复、异步结果归属、文件选区和传统拖放。测试使用隔离目录和内存剪贴板。
