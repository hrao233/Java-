# 视觉验证

2026 年 11 月 28 日在 Windows 11 25H2 x64 构建 26200.9974、Microsoft OpenJDK 21.0.13.0.2、JavaFX 21.0.6 上采集。显示器为 2560×1600，Windows 设为 150%，原生窗口 DPI 为 144。两组分别以 JavaFX 的 1.0 和 1.5 输出倍率启动。PNG 直接取自 Windows DWM 窗口区域，原生标题栏保留，像素未经缩放或合成。主窗口逻辑尺寸为 1280×800。 [采集入口](capture/run.ps1)

主窗口使用本分支编译的 `FileManagerApp`。采集驱动提供隔离目录、示例 Windows 位置和内存剪贴板。复制进度在写入样本的一部分后暂停采集，同名冲突由夹具中真实同名文件触发。未知结果用夹具模拟写入回执丢失，窗口展示了实际业务层输出的核查记录。组件展示用相同的 CSS 加载真实 JavaFX 控件和样本数据。 [主窗口驱动](../01_当前界面调查/capture/VisualAudit.java) · [组件展示入口](capture/ComponentShowcase.java)

## 本地验证

在 PowerShell 7.2 及以上版本中切换到本分支的工作树，令 `JAVA_HOME` 指向 JDK 21。下面的独立入口启动组件展示，可以手动观察悬停、按下、键盘焦点、禁用状态、菜单及选区。

```powershell
& './docs/ui-review/02_设计系统与基础组件/capture/run.ps1' -Theme dark -Scale '150%'
```

重新采集时另需装有 Pillow、openpyxl、ReportLab 的 Python 和当前 Windows 桌面会话。传入尚未创建的隔离目录，采集会将窗口 PNG 和尺寸记录放在该目录的 `Images` 内。`-ApplicationShots` 支持复用阶段 4.0 的截图编号。

```powershell
& './docs/ui-review/02_设计系统与基础组件/capture/run.ps1' -Theme dark -Scale '150%' `
    -FixtureDirectory 'D:\FileManager-UI-Review\Phase412-Recheck' -ApplicationShots 'A03,B09,C04,D06,E01,E03,E09'
```

通过 `mvn javafx:run` 可启动文件管理器。用隔离目录在**查看 → 外观预览**中切换主题。可比较单栏和双栏的焦点、菜单、搜索及列表选区，使用 **Tab** 检查键盘焦点，用 **F2** 在临时文件上检查行内输入，再将样本拖到另一栏的空目录检查落点提示。

本组验证覆盖同一 Windows 桌面的 100% 和 150% JavaFX 输出。跨屏 DPI 变化和其他桌面环境待验证。标签溢出、菜单定位和滚动箭头由 JavaFX 皮肤负责。深色模式下的原生标题栏在这台机器上仍采用 Windows 的浅色装饰。
