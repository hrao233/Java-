默认命令按配置跳过 JavaFX 集成类及一项文件身份探测。启用 JavaFX 后，跳过 3 项可选的标签、分栏、拖放基准，1 项需要另一 NTFS 卷的用例，以及 1 项所在提供者没有公开文件身份的用例。NTFS 原生操作组 18 项、Win32 句柄组 5 项全部通过。

新增测试检查实际计算出的 JavaFX 样式，包括主窗口、等待冲突的任务窗口、冲突窗和普通对话框的主题同步，已打开的右键菜单、工具提示和地址建议，以及虚拟表格的选区与 32、25 逻辑像素行高。已有未知结果用例也检查深色核查窗口和实际下拉列表。同时执行原有键盘、地址提交、重命名、双栏命令归属、拖放目标及文件任务回归。 [JavaFX 回归](../../../src/test/java/edu/files/JavaFxFileOperationsTest.java)
