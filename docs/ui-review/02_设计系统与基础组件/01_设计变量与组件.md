## 组件及状态

| 组件 | 样式和状态 |
| --- | --- |
| 按钮、图标按钮 | 普通按钮使用表面和外框，工具栏与图标按钮使用透明底并保持同一套悬停、按下和焦点样式。主按钮使用强调色和专用文字色。禁用由控件自身示义及降低透明度共同表现。 |
| 输入、搜索、行内编辑 | 输入底色、占位、选中文字和焦点共用主题色。地址编辑保留焦点下边线，行内编辑针对紧凑表格保留更小内距。 |
| 菜单、选择、工具提示 | 下拉列表、右键菜单和建议弹层共用内容表面。选中菜单项保留勾选或单选图形。复选框和单选按钮保留 Modena 的标记形状，主题控制外框、悬停、按下和选中。 |
| 标签、分隔条、滚动条 | 选中标签与内容保持同一表面，休眠标签使用窗口带。标签关闭、溢出与焦点沿用现有控件。分隔条保留拖动区域，滚动条保留滑块和方向按钮。 |
| 列表、侧栏和空状态 | 详情行选区覆盖整行，文件名用主文字，类型及日期等用次级文字。树的选区同时显示左侧条和字重。空状态沿用文字说明，读取状态沿用文字和进度指示。 |
| 任务与拖放 | 复制及移动沿用不同落点填色和底部文字说明，剪切保留淡显。任务结果继续显示明确状态文字，对部分完成、未知结果和失败加上相应色彩。 |

## 主题挂载与图标

`UiTheme` 给 Scene 一次加载调色板、通用控件和应用样式。主题预览通过**查看 → 外观预览 → 浅色或深色**切换，本次以窗口会话为范围，启动采用浅色。主题选择集中在 `UiTheme`，将来可在同一处接入系统偏好。 [主题入口](../../../src/main/java/edu/files/FileManagerApp.java) · [主题实现](../../../src/main/java/edu/files/UiTheme.java)

有独立 Scene 的任务、冲突窗绑定所有者样式列表。JavaFX 21 的 `Dialog` 绑定所有者 Stage 的 Scene 样式。再次打开 `PopupWindow` 时 JavaFX 从所属窗口复制样式，切换时 `UiTheme` 也更新当前可见的所属弹层。工具提示、右键菜单、下拉列表和应用建议弹层拥有各自的调色板作用域，可在对应皮肤的根节点解析颜色。 [未知结果核查](../../../src/main/java/edu/files/UnknownResultsDialog.java) · [地址建议](../../../src/main/java/edu/files/AddressBar.java)

`UiGlyph` 在 24 单位坐标中绘制 1.8 单位宽的圆端描边，按组件尺寸缩放。图形透明于鼠标事件，按钮仍承担命中、键盘、无障碍名称和提示。图标路径随项目源码维护，交接包未提供需要引入的第三方图标依赖。 [功能图标](../../../src/main/java/edu/files/UiGlyph.java) · [内容图标](../../../src/main/java/edu/files/SystemIcons.java)

JavaFX 仍负责菜单定位、标签溢出、滚动、虚拟单元格与弹层皮肤。Windows 负责原生标题栏、最小化和关闭按钮，标题栏颜色由系统外观决定。下一阶段的列式、混合布局可以直接使用这套颜色和控件样式，布局选择仍由各自的浏览上下文管理。
