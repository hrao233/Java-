# 4.1.1 已认可的 UI 设计参考

HTML 是交互原型；PNG 是相同原型的示例画面，不是真实 JavaFX 截图。
三种布局：传统、米勒列、混合（上方层级导航与下方文件视图）。默认传统；每个浏览上下文可选择布局，两栏可独立。
浅色蓝灰基调：chrome #EDF1F7, sidebar #F3F6FA, surface #FFFFFF, secondary #F7F9FC, text #202630, muted #596779, faint #768397, border #DDE3EC, accent #2563EB, selection #E2ECFF, hover #EDF2FA。深色参考 HTML 中 html.dark。
标准行高 32、紧凑 25、侧栏默认 186（均为逻辑像素目标）；控件圆角约 4–7。保留系统原生标题栏、文件关联图标和真实缩略图。
原型不连接磁盘；模拟数据、模拟任务、假窗口按钮以及简化控件不构成生产功能规范。原型中未呈现的既有能力须保留。交互、可访问性、DPI、布局与文件安全以真实 JavaFX 验收为准。
