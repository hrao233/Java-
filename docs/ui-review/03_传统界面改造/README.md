# 阶段 4.1.3 传统模式界面改造

在 `feature/ui-redesign` 的 `cd32d0101f3db033f45039f4e62ab74ae169897b` 基线上调整传统浏览界面，沿用 4.1.2 的浅色、深色变量及现有 JavaFX 控件。

标签栏根据标签标题和可用宽度计算大小，新建按钮随标签组移动，标签过多时保留 JavaFX 的溢出菜单。导航和工具栏减少垂直内边距，单栏搜索宽度调整为 192 逻辑像素。单栏导航的蓝色横线改为细分隔线，双栏活跃区域继续保留识别标记。后续布局切换仍可放在工具栏，当前仅显示已实现的命令。

侧栏在原目录树中增加“位置”“快速访问与收藏”“设备与位置”标题，继续使用系统图标、展开状态和既有宽度设置。详情列表在有余量时扩展名称列，窗口或可见列变化时回收自动扩展的宽度，用户可以手动调整列宽。大小、可用空间和已用空间的单元格右对齐。狭窄的双栏仍可横向滚动，排序、筛选与虚拟化沿用现有控件。状态栏减少上下留白并保留原有文字、任务及警示入口。

## 验证

使用 Windows 11、Microsoft JDK 21.0.13 和 Maven 编译，定向运行 8 项 JavaFX 集成测试，全部通过。覆盖新建、切换标签、地址输入与搜索、双栏导航、选区与行内编辑、从列表和其他标签拖放，以及名称列填充和手动调整。多标签溢出菜单通过 JavaFX 截图驱动打开。最后调整标签宽度后，额外复跑标签、列宽和拖放相关 3 项，全部通过。

截图采集使用隔离样本目录和真实 JavaFX 窗口，系统分辨率 2560×1600、Windows 缩放 150%，JavaFX 输出倍率 100%。通常窗口 PNG 为 1262×791，最小窗口为 942×541。溢出菜单截图包括弹层，宽度为 1351 像素。截图驱动通过程序操作真实控件，鼠标拖放的人工体验仍待验收。
