# 开发者快速入门

使用 Windows x64、JDK 21 和 Maven。构建可执行发行包时，采用锁定的 Microsoft OpenJDK、Maven 和 WiX。 [工具锁](../packaging/windows-lock.json)

```powershell
java -version
mvn -version
mvn test
mvn "-Djavafx.integration=true" package
mvn javafx:run
```

默认测试覆盖文件系统和任务逻辑。JavaFX 集成运行使用真实 JavaFX 场景、同步点和隔离剪贴板替身，实际 Explorer 手势由桌面验收覆盖。所有写入夹具放在单独临时目录。

`edu.files.FileManagerApp.main` 是入口。先读导航上下文与 `BrowserView`，再追踪复制从对象捕获、身份检查、暂存发布到动作回执。 [分步源码阅读路线](development/12_发布前质量审查/07_源码阅读路线.md)

验收时可以给 JVM 加 `-Dedu.files.preferencesNode=explorer-qa`，让本次窗口使用包名下的独立 Preferences 节点。常规用户入口使用 `explorer`。 [构建与发行](构建与发行指南.md)
