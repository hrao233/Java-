## 性能方法

从阶段 2.2 的完整基线源码编译独立类目录。两个 JDK 21 进程在同一块 NTFS 卷创建相同规模的独立夹具。每个时间类场景先运行一次暖机，再计五次并保留最小值、中位数和最大值。复制计时含选择核对、发布和暂存清理。夹具创建、内容核对和性能夹具销毁在计时外。目录读取时间覆盖 `LocalFiles.readDirectory` 的读取与排序。普通文件速度来自真实字节，300,000 次进度报告的微基准单独计算业务采样开销。 [基准源码](../../../src/test/java/edu/files/FileOperationBenchmark.java)

### 本机测量

相同规模执行两轮，交换两个版本启动顺序。表中为五次采样的中位数，单位 ms。

| 场景 | 首轮阶段 2.2 | 首轮阶段 2.3 | 复测阶段 2.2 | 复测阶段 2.3 |
| --- | ---: | ---: | ---: | ---: |
| 复制 192 MiB 普通文件 | 205.26 | 51.95 | 57.25 | 196.45 |
| 复制目录中 1,000 个 4 KiB 文件 | 4,907.39 | 6,265.18 | 4,783.72 | 5,797.81 |
| 单独预扫描 1,000 项 | 3.93 | 4.04 | 3.40 | 3.71 |
| 读取并排序 10,000 项 | 2,945.20 | 3,026.87 | 2,939.31 | 2,625.50 |

大文件中位吞吐随运行顺序反转。阶段 2.2 为 935 和 3,354 MiB/s，阶段 2.3 为 3,696 和 977 MiB/s。样本受运行顺序和缓存状态影响。小文件两轮都慢约 21% 至 28%，复测中位吞吐由约 0.82 降至 0.67 MiB/s。新版对各暂存条目读取原生身份，并在发布前检查清单。目录扫描本身约 3 至 4 ms，完整发布和属性处理仍包含在小文件复制耗时中。两轮的普通浏览读取分别约慢 3% 和快 11%，本次补丁沿用原目录读取与排序路径。

| 新版复测 | 最小值 | 中位数 | 最大值 |
| --- | ---: | ---: | ---: |
| 300,000 次字节报告的业务采样开销 | 35.48 ms | 36.58 ms | 66.01 ms |
| 在首个有效回调请求取消至进入清理 | 2.09 ms | 3.49 ms | 5.41 ms |
| 暂存清理至业务终态 | 1.47 ms | 1.84 ms | 2.55 ms |

微基准末次运行发出 4 个快照通知。真实界面最多每 100 ms 读取一次最新快照。小文件耗时也包含目录树清单和验证，进度微基准单独反映连续的字节报告。

### 句柄采样

每轮完成 500 次完整身份采集和 20 次实际文件复制。下列顺序是暖机轮结束、随后 24 轮结束的全进程计数。

```text
阶段 2.2  376 376 381 378 378 381 381 378 378 378 378 378 378
          378 378 378 378 378 387 378 378 378 378 378 378
阶段 2.3  386 386 386 386 386 386 386 386 395 386 386 392 389
          392 389 386 386 386 392 387 387 387 387 387 387
```

新版暖机后的计数为 386，峰值 395，最终连续六轮为 387。两版在样本窗口都有回落和平台期。全进程计数含 JVM、JNA 及后台活动，峰值来源未逐句柄归因。阶段 2.2 的 352 至 370 来自两次抽样，本次多轮数据没有观察到随采集或复制次数持续累加的趋势。

真实 JavaFX 停点测试中，取消按钮事件至业务标记 **2.01 ms**，至终态可见 **47.13 ms**。这是一次含测试轮询的集成观测，原生停止和清理用下方的独立样本衡量。系统负载、磁盘缓存、磁盘类型和目录结构会影响外推。

## 复现

在 Windows x64 的 PowerShell 7 和 JDK 21 环境中运行。默认测试与完整桌面测试使用同一 Maven 配置。

```powershell
mvn -v
mvn test
mvn '-Djavafx.integration=true' package
```

性能测试使用本地 NTFS 临时目录，并在 JVM 退出时清理其夹具。在同一工作区先运行测试，随后从 Surefire 输出读取项目测试的类路径。

```powershell
$bench = [IO.Directory]::CreateTempSubdirectory('javafx-file-manager-bench-').FullName
$archive = Join-Path $bench 'baseline.zip'
$baseline = Join-Path $bench 'baseline'
git archive --format=zip "--output=$archive" 839ef3082178957430bfa82d6773f3947a13d739
Expand-Archive -LiteralPath $archive -DestinationPath $baseline
mvn -f (Join-Path $baseline 'pom.xml') compile
$suite = ([xml](Get-Content -Raw -Encoding utf8 -LiteralPath 'target/surefire-reports/TEST-edu.files.LocalFilesTest.xml')).testsuite
$classpath = ($suite.properties.property | Where-Object name -eq 'java.class.path').value
$baselineClasses = Join-Path $baseline 'target/classes'
java "-Djava.io.tmpdir=$bench" -cp "$baselineClasses;$classpath" edu.files.FileOperationBenchmark baseline $bench
java "-Djava.io.tmpdir=$bench" -cp $classpath edu.files.FileOperationBenchmark engine $bench
```
