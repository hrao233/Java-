# 阶段 2.3 文件操作引擎

文件管理器从状态栏的「文件任务」显示当前任务或最近一次结果。持续超过 350 ms 的任务会自动打开进度窗。Windows x64 本地 NTFS 的普通文件复制显示真实传输字节，并支持在系统复制回调中取消。系统提交完成的项目会记录到结果，取消会保留其余未执行项。任务可用「核查结果」查看回执丢失时的路径，重新选择当前对象后可以发起新的操作。
