# 04 JavaFX 交互与任务调度

从菜单或工具栏发起复制、移动、重命名、回收或撤销后，状态栏的「文件任务」立即可用。较长任务延迟 350 ms 打开进度窗。关闭进度窗后可从状态栏继续查看。窗口读出当前项目、阶段、字节和结果。取消键设置业务信号，并保持「正在响应取消」「等待系统提交」或「正在清理暂存」。终点展示实际状态，错误和清理诊断带路径。 [窗口实现](../../../src/main/java/edu/files/FileOperationProgress.java)

写入仍走原有单线程磁盘执行器。主窗口在 `activeTask` 期间暂停目录切换、导航历史和新的写入。已显示的列表和预览可以查看，新的磁盘预览与其它读取仍受该执行器约束。进度窗在 JavaFX 线程处理动画、关闭与取消，写入或清理期间的磁盘等待与按钮响应独立。写入时主窗关闭事件会把焦点带回任务窗。应用结束时给活动文件任务发出合作式取消并允许磁盘线程完成退出。 [应用调度](../../../src/main/java/edu/files/FileManagerApp.java)

拆分读取队列可提高长写入期间的浏览可用性，需要同时设计页面归属、旧请求丢弃、写后刷新、选中与预览一致性，以及多个执行器的关停。当前阶段保持一个磁盘队列，原因是取消和真实进度可在这个边界验收。刷新采用真实磁盘列表，提交后剪切和撤销按项目回执更新。 [阶段 2.2 交互](../03_文件身份与撤销恢复/03_撤销交互与状态.md)
