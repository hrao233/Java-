# 产品体验与缺陷清单

基线为阶段 3.2 的 `f818debde31c92b71811ac76e7996f6ae3b9e22c`。下列问题在 Windows 11、Microsoft OpenJDK 21.0.13 上以隔离夹具复现。四项修复前测试出现两项断言失败和两项错误。

| 编号 | 严重度与发布影响 | 实际表现与复现 | 预期与处理范围 | 回归 |
| --- | --- | --- | --- | --- |
| R33-01 | P1，修复前阻塞 | 打开普通目录，在单写入线程的测试同步点排队「新建文件夹」，移走原目录并在旧路径建立同名空目录。释放线程后，新建结果落入替代目录。 | 拒绝旧请求，保留两个目录和原内容。约束 `FileManagerApp.create/createItem` 的请求归属和目标核验。 | `newFolderRefusesAReplacedDestinationWhileWaitingForTheWriter` |
| R33-02 | P1，修复前阻塞 | 保存一个含 Windows 非法字符的固定路径、一条损坏的近期时间戳及有效后续行。启动后状态停留在读取系统位置，有效近期项目未显示。 | `restorePreferences` 逐条加载路径和访问记录，跳过坏行，主页和导航继续可用。 | `malformedPreferencesDoNotBlockStartupOrDiscardValidHistory` |
| R33-03 | P2，系统位置发现退化 | 把截断的 `view`、`shell` 和非法路径、时间、大小夹在脚本输出中，`WindowsPlaces` 在解析中抛出异常。 | 拒绝坏行，保留默认系统位置及其他合法记录。 | `WindowsPlacesTest.malformedRecordsLeaveDefaultsAndLaterValidRecordsAvailable` |
| R33-04 | P2，日常设置丢失 | 调整尺寸、位置及双栏分隔条，关闭并重启。右栏恢复为关闭，几何和比例重置。 | 下次启动恢复窗口布局，浏览位置和写入凭据按新会话初始化。 | `reopeningRestoresLayoutAndPreferencesWithAFreshFileSession` |
