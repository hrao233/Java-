# 现状与历史问题复审

## 当前功能矩阵

“集成”指真实 JavaFX 场景或 Windows 原生实现参与自动化测试。阶段 3.2 的人工通过记录对应当时提交，阶段 3.3 的实际键鼠结果见本轮验收文档。 [回归](05_修复记录与回归验证.md) · [验收](06_人工验收与发布准备.md)

| 能力 | 当前能力与边界 | 证据 |
| --- | --- | --- |
| 地址、导航与历史 | 两栏独立面包屑、链路展开、编辑和建议，回车提交，前进、后退及上级。失败保留原有效位置或提示目录失效。 | `AddressBar`、`tabCommandsKeepNavigationSearchAndTextInputSeparate`、阶段 3.2 两栏回车回归 |
| 标签页和双栏 | 左栏多标签有独立历史和搜索，右栏一个上下文。支持复制标签、快捷键、活动栏、分隔条和双栏直传。已关闭的后台列表、预览和监听可释放。 | 阶段 3.0/3.1 集成、截图及桌面通过记录 |
| 快速访问、收藏、近期 | 固定目录、收藏、最近文件和最近修改。近期使用合并应用与 Windows Recent，最近修改依赖已知位置及索引。 | `restorePreferences`、本轮损坏记录启动回归 |
| 搜索、取消及恢复 | 名称查询，普通目录递归，最多 2,000 个结果。可取消和清除查询，结果可跨标签复制。 | `LocalFiles.search`、`copiesASearchResultIntoAnotherTabWithoutChangingTheSearch` |
| 列表、图标及选择 | 详细表、不同尺寸图标、列表、平铺、内容。排序、分组、列筛选、多选、右键及复选框。 | `BrowserView`、切换标签、筛选及自动刷新回归 |
| 手动和自动刷新 | F5 和按钮可刷新。两个可见的普通本地 NTFS 目录自动监听，后台标签激活时重新读取。递归搜索、图库及不可靠提供者使用手动刷新。 | `DirectoryWatcherTest`、`JavaFxFileOperationsTest` |
| 查看和打开 | 默认应用打开文件。单选文本或常见图片可预览，详情面板显示文件属性。Windows 属性由系统对话框展示。 | 预览迟到、自动刷新和身份检查测试。各默认应用及原生属性扩展待复验 |
| 图库 | 选定来源读取常见图片并生成缩略图，按名称候选和项目上限浏览。 | `LocalFiles.images`、`BrowserView` 及历史图片夹具 |
| 新建与单项改名 | 新建文件夹、注册的文件类型、文件或网址快捷方式。ShellNew 命令交外部应用。普通单项可行内改名，NTFS 支持大小写变更。 | `FileSafetyTest`、`NtfsFileOperationsTest`、本轮新建目标回归 |
| 应用内批量文件操作 | 多项复制、剪切粘贴、跨标签与跨栏、直接复制或移动、文件列表/目录/标签拖放。保留两者或跳过，单批取消，已发布项目按真实结果保留。 | `TransferConflictTest`、`FileOperationTaskTest`、JavaFX 冲突、拖放及复制回归 |
| 资源管理器互通 | 双向普通文件和目录复制，经系统剪贴板或拖放。外部剪切与外部拖放移动被拒绝，复制路径发布为文本。 | 阶段 2.6/3.2 真实桌面，系统剪贴板格式及拖放模拟回归 |
| 回收和撤销 | 回收交系统回收站。可核验的移动与改名支持单次撤销。复制和新建的删除式撤销受限。未知结果可查看并定位路径。 | `FileSafetyTest`、`NtfsFileOperationsTest`、真实界面状态回归 |
| 系统位置及工具 | 查看驱动器、UNC 入口、可用的 OneDrive/WSL 和 Shell 项。已共享页展示网络位置。映射、断开、格式化、清理和优化调用系统工具。 | 系统位置加载与解析。映射、断开及磁盘工具此次仅检查代码 |
| 设置和重启 | 保存侧栏宽度、窗口和分隔条、双栏模式、显示选项、收藏、自动刷新及近期路径。排序、分组、选择、编辑、历史和文件凭据属于浏览会话。 | `reopeningRestoresLayoutAndPreferencesWithAFreshFileSession` |

## 原始风险如何演变

| 原始编号 | 当前处置 | 证据与剩余条件 |
| --- | --- | --- |
| F01 / S08 | 已通过产品限制关闭危险逆操作 | 深层文件修改和同大小同时间文件仍保留。复制和新建的删除式撤销仍禁用。 [2.1 修复](../02_文件操作安全/02_危险撤销修复.md) |
| F02 / S09 | 已修复本地 NTFS 承诺范围 | 实际移动回执包含对象身份和目标，撤销核对两侧目录且无覆盖。NTFS 硬链接竞争仍有边界。 [3.0 复查](../09_多标签页与浏览上下文/01_架构与状态归属.md#硬链接竞争的有限回归) |
| F03 / S12 | 部分解决 | 剪贴板、移动、改名和窗内拖放在支持范围绑定原对象。首次核验之前、按路径回收、Explorer 读取源与 NIO 回退仍有窗口。本轮补上新建目录校验。 [安全范围](03_文件安全与发布边界.md) |
| F04 / S20 | 已修复批次回执 | 首次失败前的成功结果保留，逐项区分跳过、未知、取消和未执行。冲突可继续，未知项必须核查。 [冲突决策](../08_文件冲突处理/01_冲突决策与文件安全.md) |
| F05 / S17 | 产品范围限制 | 直接传输和拖放只承诺同卷移动，其他剪切路径走受限的 NIO。没有跨卷目录搬移协议。 [跨卷设计](../04_文件操作引擎/05_跨卷移动与冲突处理设计.md) |
| F06 | 已解决主要交互缺口 | 进度、冲突等待及协作式取消独立于浏览执行器。提供者阻塞和提交中的调用仍需返回，强制结束可留存暂存。 [任务取消](../04_文件操作引擎/03_复制进度与协作式取消.md) |
| F07 / S13–S14 | 部分解决 | NTFS 句柄路径拒绝重解析点祖先和目标。本地 Junction 回归已跑，普通符号链接及其他提供者组合未全面实测。 [原生回归](../../../src/test/java/edu/files/NtfsFileOperationsTest.java) |
| F08 | 部分解决 | 大小写改名、复制清理和未知回执有所改善。设备保留名仍主要由提供者拒绝，模板和快捷方式仍使用独立的暂存清理。 [本轮安全边界](03_文件安全与发布边界.md) |

历史审查中的「导航因写入禁用」「外部变化依赖手动刷新」「单窗单列表」「仅应用内剪贴板」已经过相应阶段改进。初审其余建议仍按产品范围评估，包括自然数字排序、更多预览处理器、后台搜索索引、更多选择和辅助功能。 [浏览调度](../05_浏览调度与性能优化/README.md) · [监听](../06_目录监听与自动刷新/README.md) · [初审体验建议](../../audit/09_产品体验与功能改进.md)
