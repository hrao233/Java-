# 文件安全与发布边界

工具栏、右键和快捷键共用窗口命令。粘贴、跨栏直传和拖放各自采集输入，验证来源和目的后统一进入 `submitTransfer → applyChanges → FileChanges`。改名、回收和撤销提交各自的 `Change`，新建则使用同一单写入线程的 `NewItems` 路径。接受请求后写入使用固定的来源和目标，回执只刷新受影响的目录、标签及选择。冲突等待可继续浏览，关闭提示窗口能取消剩余项目。 [窗口命令](../../../src/main/java/edu/files/FileManagerApp.java) · [操作模型](../../../src/main/java/edu/files/FileChanges.java) · [冲突边界](../08_文件冲突处理/01_冲突决策与文件安全.md)

| 条件 | 风险与现有处理 | 放行边界和使用方式 |
| --- | --- | --- |
| 捕获后同名替换 | NTFS 将对象 ID、创建时间、父目录和目录项关联，关键原生操作限制共享删除，提交前复核。对新建，目标路径需有目录身份，NTFS 持有该目录及祖先句柄直至写入和采集结果。 | 普通本地 NTFS 为主验证环境。发现旧路径指向替代品时拒绝，刷新并重新选择。 |
| 硬链接并发改动 | 检查前已占用能拒绝，NTFS 仍可能在预查和提交之间遇到同对象硬链接。检测到链接数减少时结果不确定且无撤销，反向并发可能抵消计数。 | 在明确范围的本地稳定文件操作中为已知限制。不要同时对同一对象添加或删除硬链接。此轮回归观察到原生同名拒绝且源保留。 |
| 同名目标和取消 | 严格无覆盖发布。冲突仅给跳过、保留两者、取消和后续策略。复制完成才发布正式名称，已写项可验证，清理不明对象留供核查。 | 支持范围内无待修复的已知覆盖缺陷。跳过无需重试，未知项应核对源及目标后再决定。 |
| 动态复制内容、ACL、备用流 | 目录遍历在不同时间观察各项，复制不是树快照。NTFS 复制用 `CopyFileExW` 和安全描述符，无法写全所有者、组或 ACL 时有警告。NIO 的 `COPY_ATTRIBUTES` 能力随提供者。 | 对需逐字节和 ACL 等价的归档，使用稳定源并核对内容、有效权限及备用流。本轮复验了目标 ACL 拒绝及恢复，未验证全部元数据组合。 |
| 同卷和跨卷移动 | 跨栏直传和拖放要求可核验同卷 NTFS。一般剪切粘贴可能进入确认后 NIO 移动，异卷非空目录没有端到端迁移协议。 | 跨卷目录使用复制并核对完整性。专项验证 C/D 卷直传、拖放移动均拒绝，未改变源。 |
| 外部剪切和拖放移动 | 系统剪贴板或 Dragboard 路径不能证明发起时身份。外部只支持复制。对外拖放由接收方打开源路径，`DRAG_DONE` 只清理会话。 | Explorer 用 Ctrl 复制，窗内剪切和同卷 Shift 拖放才可移动。虚拟 Shell 项、跨应用剪切和移动均在发行范围外。 |
| 链接、Junction、网络和其他文件系统 | 重解析点不能作为普通原生句柄目标，外来链接和特殊项会受入口限制。NIO 回退仅在提供者能力和已有确认下工作，路径调用与对象绑定之间仍有竞争。 | 网络、可移动盘、WSL 目录，以及身份未知时使用手动刷新。重要文件优先使用已核验的本地目录。只承诺测试所列 NTFS 场景。 |
| 系统回收站和外部 ShellNew 向导 | Windows 回收仍按路径，调用前做身份检查并要求确认。向导启动时核对工作目录，外部进程之后的写入由该程序负责。 | 回收前暂停外部重命名，同一目录内容核验后才继续。回收没有永久删除回退或应用内恢复。 |
| 新建模板、注册数据和快捷方式 | `NewItems.publish` 使用独立暂存和无替换移动，跟随目录的句柄提供目标保护。其内部暂存清理仍按路径，晚期清理失败可能让错误提示与实际落盘不一致。 | 本轮确认并修复了排队后目标替换。模板/COM/不同提供者的异常中断及针对暂存的并发改写仍需独立验证。共享可并发写入的位置优先新建普通目录或空文件。 |
| 关闭、强制退出、磁盘工具 | 正常关闭在写入中提示等待，冲突等待可以取消。强制结束可遗留隐藏暂存。系统格式化、断开网络盘和清理由系统执行。 | 本轮只用隔离测试目录验证写入和资源释放。手工检查残留时先核对路径和内容，不按前缀批量删除。 |

已验证的撤销绑定最新的同一对象，内容有编辑仍能撤回，目标重名或身份变化会拒绝。发布前的暂存和回执覆盖常规取消及故障路径，磁盘满、进程崩溃及外部工具的真实副作用没有在本轮复现。 [本轮回归](05_修复记录与回归验证.md) · [暂存实现](../../../src/main/java/edu/files/StagedCopy.java) · [原生移动](../../../src/main/java/edu/files/NtfsFileOperations.java)
