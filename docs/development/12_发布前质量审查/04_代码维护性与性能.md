# 代码维护性与性能

## 职责复审

| 模块 | 观察与本轮取舍 |
| --- | --- |
| `FileManagerApp` | 窗口协调、每栏呈现、菜单、文件请求和拖放状态集中。新建能漏掉传输入口已有的目录身份规则，因而复用目标快照和核验，保留现有写入调度。今后相同规则需要第三个入口时，从已出现的重复处提取。 |
| `BrowserView` | 表格、图标、虚拟化、行内编辑和选择恢复彼此关联。当前变更留在窗口命令及首屏加载，保留组件现有交互。 |
| `BrowseContext` 与 `BrowserPane` | 上下文拥有位置及请求生命期，区域拥有控件和监听，窗口拥有剪贴板及任务。将视图与排序留给上下文，避免改变其他标签的默认设置。 |
| 传输准备和执行 | 剪贴板、拖放及跨栏直传各有来源协议。接受后共用捕获、目标核验、冲突处理和回执。拖放手势释放与任务完成的时间不同，保留两条生命周期。 |
| `JavaFxFileOperationsTest` | 真实窗口、合成事件、内存剪贴板和可控读写同步点可复用。通过反射观察状态的断言与内部字段耦合，新增回归同时核对磁盘内容和用户可见状态。 |

## 测量环境和读数

Windows 11 26200 x64，Core i7-14650HX、15.7 GiB，本地 NTFS，Microsoft OpenJDK 21.0.13.0.2，JavaFX 21.0.6，输出缩放 150%。单进程加载后用真实场景，文件和目录属于当次夹具。保留操作系统缓存，未重启机器或清系统缓存。三次启动使用独立 JVM，计时从诊断启动类初始化到 `Stage.show` 返回及主页提交，包含 JavaFX 初始化及主页所需系统目录发现，省略进程创建前开销。

| 启动 | 窗口显示 | 主页可用 |
| --- | ---: | ---: |
| 本轮首次进程 | 708 ms | 4.99 s |
| 连续两次重启 | 623–649 ms | 2.51–2.88 s |

以下复用阶段 3.0/3.1 的 JUnit 基准。导航计时从发起请求到 FX 提交，未计入屏幕合成。双栏测试普通目录约 100 项，两边大目录各 10,000 项，先反复导航三轮再报五次样本。单标签小样本为一个文本文件。开关从点击到同步 CSS 与布局结束，写入停在 24 MiB 样本的发布同步点。在同一桌面会话做了其他诊断，读数用于描述本次环境。 [基准实现](../../../src/test/java/edu/files/JavaFxFileOperationsTest.java)

历史阶段 3.1 的双栏 10,000 项提交约 0.54–0.56 s。本轮分离读取层，用同一目录各做一次预热及三次采样，3.2 纯目录读取为 250–259 ms，3.3 为 249–264 ms。两组 JavaFX 大目录数据来自不同运行批次，差异还需同批测量读取等待、筛选及场景提交。大页交互是后续可定位的性能项，本轮没有围绕差异修改浏览实现。 [阶段 3.1 历史读数](../10_双栏浏览与跨栏操作/02_验证与人工验收.md#性能与资源) · [读取层](../../../src/main/java/edu/files/LocalFiles.java)

## 资源和窗口关闭

请求 GC 后，单栏 10,000 项约 26.93 MiB，双栏各 10,000 项约 37.20 MiB，十次开关后关闭右栏约 32.57 MiB。对应工作线程 7、8、8，监听键 2、4、重复双栏时 4、关闭右栏后 2。标签由 2 增加至 22 再回到 2，堆为 23.16、25.00、25.07 MiB，应用工作线程均为 6。后台标签断言不保留完整列表、预览任务和监听目标。

诊断重复创建/关闭标签、开启/关闭双栏并读取夹具，采样前请求 GC。句柄数由 Windows `GetProcessHandleCount` 返回，线程数为 JVM 管理接口记录的 Java 线程。图标缓存为 52 项，夹具仅有文本/二进制文件，缩略图为 0，双栏活动监听键各次均为 4。关闭右栏时还等待其注册归零。
