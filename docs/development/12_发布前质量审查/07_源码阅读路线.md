# 从 Java 基础开始阅读源码

可以先用 JDK 21 执行 `mvn javafx:run`，在两个临时目录里复制一个文本文件。带着“谁记录了我的选择、谁真的写了磁盘、谁更新了界面”三个问题读代码。每一步只需读该调用附近的方法。 [构建配置](../../../pom.xml)

1. 从 `FileManagerApp.main` 和 `start` 开始。JavaFX 创建窗口并将菜单、按钮和快捷键连接到方法。先顺着地址栏回车找到左栏或右栏的 `navigate`，观察何时更新历史，何时显示错误。 [FileManagerApp](../../../src/main/java/edu/files/FileManagerApp.java) · [AddressBar](../../../src/main/java/edu/files/AddressBar.java)
2. 区分目录中的文件和界面上的一行。 `LocalFiles.Entry` 是一次文件系统读取，`BrowserItem` 是其展示对象，`BrowserView` 把行放进表格或图标视图。 `BrowseContext` 记录当前目录、查询、历史、视图和请求。两个可见的浏览区域分别接受属于自己的结果。 [LocalFiles](../../../src/main/java/edu/files/LocalFiles.java) · [BrowserItem](../../../src/main/java/edu/files/BrowserItem.java) · [BrowseContext](../../../src/main/java/edu/files/BrowseContext.java) · [BrowserView](../../../src/main/java/edu/files/BrowserView.java)
3. 跟踪复制按钮到粘贴。复制阶段保存已选对象的凭据，必要时发布标准文件列表。粘贴读取剪贴板版本及本窗会话，用 `transferTarget` 固定目标，再由 `preparePaste` 核验和接受。若把目标原目录移走后创建一个同名目录，路径文字相同也可能指向新对象。读 `DirectoryIdentity` 和 `FileChanges.Selection` 看这两种对象如何被区分。 [FileClipboard](../../../src/main/java/edu/files/FileClipboard.java) · [DirectoryIdentity](../../../src/main/java/edu/files/DirectoryIdentity.java) · [FileChanges](../../../src/main/java/edu/files/FileChanges.java)
4. 顺着 `submitTransfer`、`FileChanges.transfer` 和 `LocalFiles.copy` 读到 `StagedCopy`。大文件的写入可能被取消，先写任务的暂存目录才能避免把半写完的文件放到正式路径。正式提交时才决定名称，重名时可以停下来等待用户。 [StagedCopy](../../../src/main/java/edu/files/StagedCopy.java) · [TransferConflict](../../../src/main/java/edu/files/TransferConflict.java)
5. 从 `FileOperationTask` 回到窗口。工作线程发布进度和每项结果。回执保存实际目标，因而「保留两者」的刷新和撤销都能找到正确文件。 `BrowseImpact` 只让相关位置重读，界面更新在 JavaFX 应用线程执行。慢读可能晚到，`BrowserPane.owns` 会判断结果是否仍属于当前显示的上下文。 [FileOperationTask](../../../src/main/java/edu/files/FileOperationTask.java) · [BrowseImpact](../../../src/main/java/edu/files/BrowseImpact.java) · [ReadExecutor](../../../src/main/java/edu/files/ReadExecutor.java)
6. 用故障定位训练一次。按钮无响应先检查焦点、事件消费和 `fileCommandsUnavailable`，再核对当前请求与提交状态。目标不对时先查看任务接受时的路径和身份、写入回执以及实际磁盘内容。若磁盘正确而界面旧，检查 `BrowseImpact`、监听通知和列表提交。为能复现的故障加同步点，用 `@TempDir` 验证内容、路径及状态，再运行对应的测试。 [JavaFX 场景测试](../../../src/test/java/edu/files/JavaFxFileOperationsTest.java) · [文件安全测试](../../../src/test/java/edu/files/FileSafetyTest.java)
