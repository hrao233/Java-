# 05 回归测试与性能验证

测试环境为 Windows 11 x64、Microsoft OpenJDK `21.0.13.0.2+1-LTS`、Maven 3.10.0 及项目中的 JavaFX 21.0.6。性能和 NTFS 集成在同一块本地 NTFS 卷进行。测试只写各自的隔离夹具，JavaFX 测试用内存偏好。

| 版本及执行方式 | 发现 | 通过 | 跳过 | 失败或错误 |
| --- | ---: | ---: | ---: | ---: |
| 阶段 2.3 `mvn test` | 70 | 68 | 2 | 0 |
| 阶段 2.3 启用 JavaFX 的 `package` | 70 | 69 | 1 | 0 |
| 阶段 2.4 `mvn test` | 76 | 74 | 2 | 0 |
| 阶段 2.4 启用 JavaFX 的 `package` | 76 | 75 | 1 | 0 |

本机 Windows NIO 的 `fileKey()` 为空，旧的稳定文件键专用用例被跳过。默认执行另外跳过需明确启用的真实 JavaFX 集成。阶段 2.4 增加六项常规回归，并扩充真实窗口场景。日志记录 JavaFX 未命名模块的启动警告。五张 Mermaid 图已通过 Mermaid 11.12.2 和 Chrome 158 的 SVG 渲染验证。 [NTFS 暂存和 ACL](../../../src/test/java/edu/files/StagedCopyTest.java) · [真实控件](../../../src/test/java/edu/files/JavaFxFileOperationsTest.java)

| 验收方向 | 场景 |
| --- | --- |
| 新旧请求 | 用锁存器让旧名单和旧预览在新结果后返回。核对页面、历史和预览。失败导航保留当前有效页面。 |
| 目录和写入竞争 | 读取期间替换目录，按身份拒绝过期结果。目录移走后刷新、清空并通过历史恢复。发布时同时读取受影响目录和无关目录，分别验证重读及保留当前导航。 |
| 写入期间交互 | 48 MiB 复制停点期间刷新、前进后退、搜索及预览。核对写入命令按钮、正式目标、活跃暂存及外来同前缀对象。 |

## 同夹具目录测量

每组先暖机一次，再取五次记录的中位数。纯枚举、逐项获取 DOS 属性和构建条目、排序、构建浏览条目、完整读目录分别计时。两个版本分别运行相同测试程序，两组文件都是同一块 NTFS 卷上的零字节文件。表内单位为毫秒。 [I/O 基准](../../../src/test/java/edu/files/Phase24IoBenchmark.java)

| 场景 | 阶段 2.3 `file-N.txt` | 阶段 2.4 `file-N.txt` | 阶段 2.3 `item-N` | 阶段 2.4 `item-N` |
| --- | ---: | ---: | ---: | ---: |
| 枚举 10,000 条路径 | 8.77 | 9.95 | 7.52 | 6.95 |
| 属性、筛选和条目构建 | 184.92 | 189.81 | 315.51 | 284.87 |
| 排序 | 1.06 | 1.09 | 1.04 | 0.96 |
| 构建浏览条目 | 0.96 | 0.91 | 0.86 | 0.71 |
| 完整目录读取 | 196.20 | 191.20 | 258.27 | 270.76 |

两份历史数据约为 300 ms 和 3 s。阶段 2.2 使用 `file-N.txt`，阶段 2.3 使用 `item-N`。两者原测量都覆盖读取和排序，均未计入 JavaFX 渲染。当前同环境可把两种命名的整体时间分开，差异集中在属性取得和构建，并未复现十倍差距。历史运行未保存足以分离缓存和系统负载的观测，原因不能精确归因。 [阶段 2.2 性能](../03_文件身份与撤销恢复/04_性能与回归验证.md) · [阶段 2.3 性能](../04_文件操作引擎/06_回归测试与性能验证.md)

## 复现

在 Windows x64 本地 NTFS 环境中使用 PowerShell 7 和 JDK 21。JavaFX 验证需要可用的桌面会话。生成的基准子目录由运行器清理。

```powershell
mvn -v
mvn test
mvn '-Djavafx.integration=true' package
$work = [IO.Directory]::CreateTempSubdirectory('javafx-phase24-measure-').FullName
$archive = Join-Path $work 'baseline.zip'
$baseline = Join-Path $work 'baseline'
git archive --format=zip "--output=$archive" 996c839d02462677e06c98d849543823bd9edaf0
Expand-Archive -LiteralPath $archive -DestinationPath $baseline
mvn -f (Join-Path $baseline 'pom.xml') compile
$report = ([xml](Get-Content -Raw -Encoding utf8 -LiteralPath 'target/surefire-reports/TEST-edu.files.LocalFilesTest.xml')).testsuite
$cp = ($report.properties.property | Where-Object name -eq 'java.class.path').value
$old = (Join-Path $baseline 'target/classes') + ';' + $cp
foreach ($mode in @('listing','copy','cancel')) {
    java "-Djava.io.tmpdir=$work" -cp $old edu.files.Phase24IoBenchmark $mode $work
    java "-Djava.io.tmpdir=$work" -cp $cp edu.files.Phase24IoBenchmark $mode $work
}
java "-Djava.io.tmpdir=$work" -cp $old edu.files.Phase24FxBenchmark baseline $work
java "-Djava.io.tmpdir=$work" -cp $cp edu.files.Phase24FxBenchmark current $work
java "-Djava.io.tmpdir=$work" -cp $cp edu.files.Phase24IoBenchmark diagnose $work
```
