# 本地文件管理器 1.0.0

首个 Windows x64 版本。可用标签和双栏整理文件，支持本地 NTFS 自动刷新、文本和图片预览、同名冲突处理、同卷移动和撤销，并能与资源管理器双向复制。

## 资产

| 文件 | 用途 |
| --- | --- |
| `JavaFXFileManager-1.0.0-windows-x64-portable.zip` | 解压完整目录，双击 `JavaFXFileManager.exe` |
| `JavaFXFileManager-1.0.0-windows-x64-setup.exe` | 当前用户安装，开始菜单及可选桌面快捷方式 |
| `SHA256SUMS.txt` | 核对下载文件 |
| `JavaFXFileManager-1.0.0-third-party-sources.zip` | 随二进制提供的 OpenJDK、OpenJFX 和 WiX 源码 |

默认支持环境为经过桌面验证的 Windows 11 x64 与本地 NTFS。Windows 10、网络目录及其他文件系统的行为仍有验证边界。程序和安装器均为未签名构建。

安装或解压位置应使用 Windows 当前系统代码页可表示的字符。英文含空格的路径已在托管环境通过验证。中文含空格的路径在本次中文 Windows 11 桌面验收通过。

便携版和安装版均自带 Java。设置保存于 Windows 当前用户注册表。跨应用传输仅支持复制，同名覆盖、目录合并、完整跨卷目录移动在当前发行范围外。 [用户手册](../../用户使用手册.md) · [安全边界](../12_发布前质量审查/03_文件安全与发布边界.md)
