# 打包、依赖与分发

以 `pom.xml` 的 1.0.0 构建应用 JAR。Microsoft OpenJDK 21.0.13.0.2 的 jlink 裁剪模块，jpackage 生成 Windows x64 主启动器及控制台诊断入口。JavaFX 21.0.6 使用 base、controls、graphics 的 Windows x64 Maven 发布件，运行时用应用镜像的相对模块路径加载。JNA 5.17.0 只保留 Windows x64 dispatch DLL，ICU4J 79.1 保持原包。资源脚本从应用 JAR 读取，由系统自带 Windows PowerShell 执行。Windows 11 的 Shell、COM 和系统图标仍在运行时调用同一系统 API。 [打包脚本](../../../scripts/build-windows.ps1) · [系统集成](../../../src/main/java/edu/files/WindowsPlaces.java)

`jdeps` 静态列出 java.base、java.desktop、java.logging、java.prefs 和 javafx.controls。实际打包另保留 java.management、jdk.charsets、jdk.localedata、jdk.unsupported 和 jdk.zipfs。裁剪镜像附带对应模块的原始 `legal`。测试用独立 JavaFX、JNA 缓存检查 DLL 提取。 [锁定工具与依赖](../../../packaging/windows-lock.json)

EXE 从同一应用镜像由 WiX 3.14.1.8722 生成，使用稳定 Windows 升级标识、当前用户安装、安装目录选择及快捷方式选择。生成的 EXE 没有 Authenticode 签名，环境中无可用的代码签名证书。配置位于当前用户注册表，安装器管理程序文件和快捷方式。 [WiX 发布件](https://github.com/wixtoolset/wix3/releases/tag/wix3141rtm) · [构建指南](../../构建与发行指南.md)

## Microsoft 运行库的分发依据

候选 ZIP 的 `runtime/bin` 有 `msvcp140.dll`、`vcruntime140.dll` 和 `vcruntime140_1.dll`，版本均为 14.44.35208.0。`javafx-graphics-21.0.6-win.jar` 包含同名文件以及 `msvcp140_1.dll`、`msvcp140_2.dll`，版本均为 14.36.32532.0。两处各有 `ucrtbase.dll` 和 15 个 UCRT API 转发 DLL，文件版本分别为 10.0.22621.5040 与 10.0.17763.132。
