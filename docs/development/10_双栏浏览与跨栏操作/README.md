# 阶段 3.1 双栏浏览与跨栏操作

从阶段 3.0 正式交付提交 `12aede7b46b598bea6bdd136f7d50f38ad4dc3e2` 开始，在独立工作树开发 `feature/phase-3.1-dual-pane`。历史设计、硬链接竞争和人工验收记录保留在阶段 3.0 文档。 [阶段 3.0 交付](../09_多标签页与浏览上下文/README.md)

工具栏的「双栏」打开右栏，拖动中间分隔条调整宽度。左栏保留标签组，右栏保留一个独立页面。点击任意一栏或按 F6 切换活跃栏，顶端共享命令、侧栏与右侧检查器随活跃栏工作。

| 操作 | 入口 |
| --- | --- |
| 单栏与双栏切换 | 工具栏「双栏」「单栏」 |
| 切换活跃栏 | 点击对应列表、地址导航或搜索框，或按 F6 |
| 手动刷新 | F5 刷新活跃栏，导航行的刷新按钮刷新所在栏 |
| 文件剪贴板 | 在来源栏 Ctrl+C 或 Ctrl+X，在目标栏 Ctrl+V |
| 直接复制 | 工具栏「复制到对栏」或 Ctrl+Shift+F5 |
| 直接移动 | 工具栏「移动到对栏」或 Ctrl+Shift+F6 |
| 标签页操作 | 左栏标签保持原有操作。右栏活跃时 Ctrl+W 收起右栏，Ctrl+T 和 Ctrl+Tab 继续操作左栏标签组 |
