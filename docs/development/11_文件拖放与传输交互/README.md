# 阶段 3.2 文件拖放与传输交互

从阶段 3.1 正式交付 `e03da6a147945847606d839e86575ff1f7f50471` 开始。开发分支为 `feature/phase-3.2-drag-and-drop`。 [双栏及直接跨栏传输](../10_双栏浏览与跨栏操作/README.md)

在详细信息、图标等文件视图中拖动一个或多个文件和目录。松开位置可以是普通目录列表的空白区、实际文件夹或已核验目录的标签。默认复制，Ctrl 明确复制，Shift 请求同卷移动。绿色高亮表示复制，蓝色高亮表示移动，底栏同时显示操作和目标。目录标签接收文件后保留当前标签。

与资源管理器交换普通文件及目录使用 JavaFX 的标准文件拖放格式，协议只提供 COPY。拖出前先选中项目，待来源核验后按住 Ctrl 拖动。资源管理器的真实鼠标双向互通随桌面验收记录。
