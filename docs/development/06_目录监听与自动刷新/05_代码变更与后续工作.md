## 剩余风险和建议

- 外部应用可能在名单读取结束到界面提交之间继续改写。事件会触发下一次取样。500 ms 限制的是单批事件合并时间，排队、I/O、显式导航及行内编辑都可延迟可见更新。采用更细粒度的列表差分前，可用同夹具验证其是否降低 FX 提交时间并维持正确选区。
- 在具备专用 SMB 夹具后再决定远程监听支持范围。验收应包含断连、重连及同名目录替换，并比较单次状态核对与定期全量枚举的成本。
- 搜索、图库、收藏和树分支可以从可计数的可见位置注册开始评估。验收应覆盖注册资源上限、两个消费者共享同一路径及关闭某个消费者后的隔离。
- 当前选区使用已验证的身份样本。若后续需要在百万项目录保留特别大的选区，可先验证 Windows 批量文件 ID 读取和现有句柄证明的一致性。
