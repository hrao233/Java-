## 同机基准

两个版本运行同一个基准类和相同生成规则。普通目录分别预先包含 100 和 10,000 个零字节文件，单次文件变更在夹具中创建。单项和万项样本先暖机一次，再记录五次中位及范围。延迟起点为外部写入开始，终点为新条目实际进入 JavaFX 页面状态。测试同时触发 Scene 布局和像素读取，表内可见延迟采用页面提交时刻。阶段 2.4 外部写入后被动等待 1.2 秒，观察到零次读取且页面无更新，其余基线延迟在手动刷新后计量。 [测量代码](../../../src/test/java/edu/files/Phase25WatchBenchmark.java)

| 场景 | 阶段 2.4 | 阶段 2.5 |
| --- | ---: | ---: |
| 约 100 项，单次变化到可见 | 手动 23.04 ms（20.12–24.17） | 自动 168.62 ms（168.07–176.30） |
| 约 10,000 项，单次变化到可见 | 手动 313.56 ms（264.61–341.78） | 自动 388.35 ms（370.80–407.82） |
| 约 10,000 项，FX 提交工作 | 5.93 ms（4.88–7.83） | 1.79 ms（1.36–7.99） |
| 10,000 项，第一次导航提交到注册补读结束 | 首次 419.69 ms | 首次 408.91 ms，补读结束 742.98 ms |
| 万项读取停点期间切到另一目录 | 45.42 ms | 30.66 ms |
| 500 项突发，最后一项可见时间与读取次数 | 手动 133.66 ms，1 次 | 自动 277.89 ms，1 次 |
| 45 次连续变化，每项可见延迟 | 停止写入再手动刷新，中位 1,117.97 ms，最大 2,146.09 ms，1 次读取 | 中位 262.75 ms，最大 534.59 ms，4 次读取 |
| 48 MiB 复制在发布停点，外部项可见 | 手动 7.73 ms | 自动 165.70 ms |
| 同一复制释放停点，正式目标可见 | 11.35 ms | 13.62 ms |

两个版本的单项组均为 6 次变化对应 6 次读取，含一次暖机。500 项耗时从本轮首个文件写入前开始计算。持续变化采用约 45 ms 一次的写入节奏。5 秒空闲采样没有产生任何目录读取。阶段 2.4 与 2.5 的进程 CPU 分别为 171.88 和 125.00 ms，进程内其他线程也计入该值。24 次切换后，阶段 2.5 的注册数至多为 2、协调线程为 1，初始、峰值和最终进程句柄分别为 937、944 和 944。阶段 2.4 对照为 947、951 和 951。关闭后在阶段 2.5 验证协调线程已退出、注册数归零，整个进程仍有 925 个句柄。 [资源采样代码](../../../src/test/java/edu/files/Phase25WatchBenchmark.java)

单次停点和空闲测量反映当次调度与资源状态。文件复制的测量覆盖发布前的同时浏览，持续带宽竞争和长周期资源走势需要另测。500 ms 是事件合并上限，本次连续写入中实际最大可见延迟包含读取与界面提交。注册补读是新打开目录的额外工作，首个页面可先显示。

### 复现

```powershell
mvn -v
mvn test
mvn '-Djavafx.integration=true' package
$work = [IO.Directory]::CreateTempSubdirectory('javafx-phase25-measure-').FullName
$archive = Join-Path $work 'baseline.zip'
$baseline = Join-Path $work 'baseline'
git archive --format=zip "--output=$archive" 2caac10c9ae38d7dc4b2f4383c0c17b1e9a6d3bb
Expand-Archive -LiteralPath $archive -DestinationPath $baseline
mvn -f (Join-Path $baseline 'pom.xml') compile
$report = ([xml](Get-Content -Raw -Encoding utf8 -LiteralPath 'target/surefire-reports/TEST-edu.files.JavaFxFileOperationsTest.xml')).testsuite
$cp = ($report.properties.property | Where-Object name -eq 'java.class.path').value
$original = (Join-Path $baseline 'target/classes') + ';' + $cp
java "-Djava.io.tmpdir=$work" -cp $original edu.files.Phase25WatchBenchmark baseline $work
java "-Djava.io.tmpdir=$work" -cp $cp edu.files.Phase25WatchBenchmark current $work
mvn '-Djavafx.integration=true' '-Djavafx.captureDirectoryWatch=true' '-Dtest=JavaFxFileOperationsTest' test
```

最后一条命令在 JVM 临时目录生成 `external-change.png`，并打印 `PHASE25_SCREENSHOT` 路径。基准运行器清理自己创建的夹具子目录。
