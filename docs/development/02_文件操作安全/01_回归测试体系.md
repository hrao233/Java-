# 01 回归测试体系

JUnit Jupiter 5.11.1 与 Maven Surefire 3.5.5 负责运行项目内回归。以 JDK 21 作为最低运行基线，两套测试都可直接调用包内逻辑。见 [pom.xml](../../../pom.xml)。

```powershell
java -version
mvn -version
mvn -B test
mvn -B package
mvn -B '-Dtest=FileSafetyTest' test
```

`mvn -version` 的 Java 应指向希望使用的 JDK。默认使用项目的 Maven 依赖解析，离线可在依赖预先缓存后加 `-o`。报告在 `target/surefire-reports/`。Surefire 的 “Tests run” 含跳过项，执行数需要扣除它们。

每个用例用 `@TempDir` 创建自己的目录。所有目标、替代文件、时间戳修改和假回收站都在这个目录。`LocalFiles.RecycleBin` 接收路径，测试替身只在夹具内移动样本或制造预期失败。默认 Maven 套件不启动桌面、Windows 工具或真实回收站。真实回收站的集成验证若另做，应与默认套件隔离，独立记录回收和恢复结果。见 [回收边界](../../../src/main/java/edu/files/LocalFiles.java#L329) 和 [故障注入](../../../src/test/java/edu/files/FileSafetyTest.java#L215)。

| 临时探针 | 本阶段处理 |
| --- | --- |
| `SafetyProbe` | 迁移复制文件与目录、同目录命名、无覆盖、后代拒绝、同名替换、深层编辑、时间戳不变、撤销目标消失、原路径被占用及 Unicode 等场景。长期套件直接走包内 API。 |
| `BatchTrashProbe` | 用假回收器实现第一项成功、第二项出现桌面 API 的 `IllegalArgumentException`、第三项未执行。另用真实目的路径冲突覆盖普通 `IOException` 路径。 |
| `FxProbe` | 作为独立可交互桌面验证。用透明 Stage、内存 Preferences、真实控件事件及夹具。新增对确认、撤销提示、批次刷新和剪切余项的检查。 |
| `PerfProbe` | 保留为原审查的独立性能实验。耗时依赖机器和缓存，默认回归验证安全与结果，避免以固定耗时阈值判定功能正确。 |

[LocalFilesTest](../../../src/test/java/edu/files/LocalFilesTest.java) 覆盖文件内容、目标路径、副本后缀、目录结构、同名数据保留、大小写与 Unicode，并检查正常复制无暂存残留。特殊路径用例只验证参数拒绝和现有数据保持。[FileSafetyTest](../../../src/test/java/edu/files/FileSafetyTest.java) 同时检查底层字节和命令结果。它验证不安全逆操作的拒绝信息、后续项状态、剩余剪切与撤销记录，并检查失败复制的暂存清理。

在能提供稳定 `fileKey` 的文件系统上，`undoesAnUnchangedMoveWhenTheProviderExposesStableKeys` 还要求真实移动可撤回。本机 Windows 两个 JDK 均报告提供者无法给出身份，这个用例各跳过一次。其它用例明确验证对应的拒绝分支，跳过情况见 [实际测试结果](06_测试与变更记录.md)。
