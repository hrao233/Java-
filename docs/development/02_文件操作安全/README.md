# 阶段 2.1 文件操作安全

文件复制与新建的自动撤销已停用。撤销不会因外层目录或文件的元数据相同而移除后续写入。移动与改名的逆操作需要能核对原对象身份、写入后的目标身份和原父目录。Windows 的 JDK 21 和 27 在本机 NTFS 上均未通过 Java API提供 `fileKey`，因此本机拒绝这两类自动撤回。

批次现在保留每一项的结果。第一项成功、第二项失败时，窗口重新读取目录，剪切队列保留失败、未知和未执行项。回收或移动请求发出后若无法确定结果，会显示当时查到的路径状态，等待用户检查。见 [批量操作结果](03_批量操作结果修复.md)。

本地 `main` 的 `d22d680` 加原有工作树改动是实现前基线。原审查文档保留为历史证据。F01 的三类危险自动删除已停用。F04 的可预期异常和部分成功已修复。F02、F03 已加身份核对、拒绝和路径确认策略。原生身份桥接与检查到执行之间的竞态留在专项设计中。见 [原文件安全审查](../../audit/06_文件操作与数据安全.md)。
