# 阶段 2.6 系统剪贴板与文件传输

Windows x64 上可以通过系统剪贴板交换真实文件和文件夹。复制使用标准文件列表，同一份内容可重复粘贴。剪切保留在发起窗口内，继续使用文件身份校验、单写入队列和真正的移动回执。Ctrl+C、Ctrl+X、Ctrl+V 与工具栏、右键菜单共用入口。文件右键菜单和 Ctrl+Shift+C 可以复制带引号的路径文本。
