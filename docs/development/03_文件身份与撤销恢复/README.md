# 阶段 2.2 文件身份与撤销恢复

Windows x64 本地 NTFS 的普通文件和文件夹可以撤回同卷移动和改名。应用在复制、剪切或开始改名时采集身份，在实际执行前再次核对。移动使用已打开的源对象和目标目录句柄，撤销也走同一条路径。用户原地编辑内容后，撤回会带回最新内容。原名已被占用、父目录被替换或对象无法再次验证时，应用拒绝撤回。

普通 NTFS 复制、剪切和改名免除额外身份确认。原生能力不适用时沿用阶段 2.1 的 NIO 策略。复制、新建的删除式撤销仍停用。回收继续通过系统确认和路径接口执行。阶段 2.1 的源码、配置和测试已补齐到 GitHub，审查文档仍可查阅。[阶段 2.1 封存基线](https://github.com/hrao233/Java-/commit/42538b5a229a6844ee9d1bdde27a0234bd3cd86d) · [原工程审查](../../audit/README.md)
