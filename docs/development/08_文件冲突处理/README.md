# 阶段 2.7 文件冲突处理

复制和移动遇到确定的同名冲突时可跳过当前项目、保留两者或取消剩余操作。勾选「对后续同类冲突应用相同策略」后，当前任务内来源和目标类型分别相同的冲突沿用该选择。进度窗口统计已跳过项目，并显示实际写入路径。

Windows 本地 NTFS 支持保留两者。同卷移动通过原对象的句柄改名，撤销使用实际移动到的名称。目录冲突可保留两棵独立的目录树。在缺少可信来源或目标目录凭据的回退路径上，冲突提供跳过和取消。窗口等待期间可继续浏览和自动刷新。
